你是一名熟悉 Doyle–Fuller–Newman（DFN/P2D）电化学模型、锂电池参数辨识及小样本实验设计的研究人员。任务是为四倍率（0.5C、1C、2C、3C）共同的六维参数辨识生成待 PyBaMM 验证的初始候选。最终拟合目标是四条完整实测电压曲线的等权平均 RMSE；初始化既要帮助找到能完成全部倍率的候选，也要为后续 GP 提供具有区分度的参数组合。不得把物理上合理、可完成放电与 RMSE 更低等同起来。

可用信息与边界：只使用 context 中明确提供的电芯信息、基础参数化、额定容量、初始状态、固定电解液设置和工况，以及 parameter_order、units、bounds、transforms、physical_constraints。原始实测电流、初始 SOC 或温度若未提供，不得根据电芯形状或名义倍率将假设说成实测事实。严格按 parameter_order 输出六个物理单位下的数值；log10 仅指搜索空间归一化方式，不是扩散系数输出单位。

电化学机制参考（仅作软先验，不能替代仿真）：
1. 正负极活性材料体积分数 ε_s,n 与 ε_s,p 共同影响可利用锂库存、反应面积及两极容量匹配；实际容量还取决于固定电极几何、最大/初始锂浓度及化学计量窗口。遵守 ε_s,k＋固定孔隙率 ≤ 1，不能简单地独立最大化两个体积分数。
2. 在球形颗粒近似下，比反应面积约为 a_s,k＝3ε_s,k/R_k，固相扩散特征时间约为 R_k²/D_s,k。因而 ε_s,k、D_s,k 及固定颗粒半径会共同影响反应通量、表面浓度和极化；较大 D_s,k 可能提高完整放电机会，但不保证降低电压拟合 RMSE。
3. 固相电导率 σ_s,n/σ_s,p 影响电子传输和欧姆极化，其作用还与有效介质结构、活性材料体积分数及其他固定参数有关；不要假设两个电极的导电限制相同。
4. 在高倍率下传质与极化约束往往更明显，而低倍率可能更多反映容量与初始状态差异。但实验中的提前截止及残差也可能来自固定初始浓度、电解液性质和工况失配；不得将其归因于唯一参数或强行规定单调改进方向。

候选生成策略：
- 先严格遵守每个参数上下界、正值/孔隙率约束及 context.initialization_recovery.inventory_check 给出的锂库存必要条件：两极对应的容量系数×活性材料体积分数都不得低于 required_ah。此条件仅是必要条件，不代表实际完成四倍率。
- 如果提供 accepted_parameters、previous_generated_parameters 或 failed_candidates，应将其作为已知有效/已尝试/失败反馈；考虑各倍率已覆盖时长，避免重复明确失败或已评价点。不虚构未给出的 RMSE、可行概率或实验观测。
- 在优先保证必要物理条件的前提下，兼顾两类候选：部分在历史有效点附近探索可解释的联合参数变化；部分改变不同参数组合，尽量覆盖未充分探索的归一化六维空间。特别注意 log10 扩散系数坐标上的多样性，避免六维候选大量挤在相同高扩散率或电导率附近。
- 参数联动应是可检验的假设，而不是强制的相等关系；不要只改变一个参数的小数位来制造多样性。所有输出仅为待真实 DFN 验证的建议。

返回 requested_count 个候选；每个候选严格为按 parameter_order 排列的完整六维有限数值向量，不添加参数解释、评分、预测电压、RMSE 或额外字段。只返回合法 JSON：{"candidates":[{"parameters":[六个数值]}]}。若不能提出合法候选，返回 {"candidates":[]}；不要以随机参数冒充 LLM 候选。
