## 结论

随机候选电压先降到 2.5 V 是该候选下正常触发的物理终止条件，本身不证明 DFN 错误。当前优化无法启动的直接原因，是完整曲线评价拒绝了所有初始候选，同时协议/实现没有定义零有效初始样本时的后续搜索办法。这个可行性处理缺口发生在 LLM 分组、GP 拟合和 Composite EI 正式开始之前，因此尚不能用它评价 LLM 增强 GP 的科学效果。

Reference 的评分规则与我们不同，能够给这些短曲线打分，但其评分存在覆盖范围随候选变化的问题。它不能直接解决完整四倍率辨识的科学评价需求。

## 源码证据

| 环节 | Reference 实际行为 | 当前实际行为 |
|---|---|---|
| 物理终止 | 放电至 2.5 V | 最低电压事件 2.5 V；复跑 32/32 确认 |
| 评价时间点 | 将实测电压插值到 simulation_time，在这些点计算 MSE/RMSE | 将仿真电压对齐到预先固定的完整实测时间网格 |
| 提前结束 | 已求解的短曲线仍可得到数值分数，缺失尾部没有进入该 MSE | 没有完整 RMSE 标签，保存原短曲线和覆盖错误 |
| 超出实测区间 | interp1d(..., fill_value="extrapolate") 允许对实测曲线外推 | 拒绝外推 |
| 异常求解 | evaluate_point 捕获异常返回 score=-1e6 | 不把任意罚分当作完整曲线 RMSE 标签 |
| 工况 | 优化函数主要读取并拟合 1C；末尾另有 2C 仿真 | 一组六参数联合评价 0.5C/1C/2C/3C |
| 有效样本不足 | 无法凭代码证明 Reference 正确解决了该问题；短曲线/异常罚分可向优化器提供数值 | _fit_models 要求至少两个四倍率有效点，未达到则终止 |

Reference 的关键表达式为 `interp1d(time_data, voltage_ref, ..., fill_value="extrapolate")(simulation_time)`，随后求 `mean((voltage_sim - voltage_ref_interpolated)**2)`。这明确以仿真自己的时间网格作为评分域。Reference 原主优化返回负 MSE；单独绘图单元还计算 RMSE。本审计没有把其单倍率实现称作四倍率算法。

将该逐曲线表达式应用于保存的 32 条短曲线，全部获得有限部分曲线分数；当前完整网格有效分数为 0/32。结果保存在 partial-score-comparison.json，仅用于规则比较，不作为 GP 标签或新正式结果。

可复算的反例保存在 short-prefix-counterexample.json：实测持续 4 s，仿真仅到 1 s，前缀电压完全一致时 Reference 风格 RMSE 为 0，但仍有 75% 时长未比较。该反例说明评价域变化可能漏掉提前结束带来的拟合缺失；不表示本次所有短曲线实际误差都小。

## 方法与实现的缺口

Method v0.2 要求每倍率完整曲线 RMSE，目标为四倍率 RMSE 等权平均，并明确失败求解计入预算、不伪造 GP 标签。它使用有效域 Theta_valid，但没有完整说明如何在宽参数域内找到有效初始点、零有效样本时如何继续，或如何将该成本纳入消融预算。

当前实现遵守完整网格和无伪造标签原则，却在没有足够有效初始点时直接报错。软件单元测试和合成闭环通过只能证明已定义路径正常，不能证明真实电池辨识协议已经覆盖这类常见边界情形。此前笼统称“框架搭建完成”应限定为软件框架与合成验证通过；实测流程的可行性初始化/恢复方案仍待明确。

另外，固定 Chen2020 设计与本组实测数据的匹配仍有未验证部分。21700 外形一致不能独立证明完整参数化相同；I 列为空，当前电流由 Reference 5 Ah 设计推算。此前电解液 1.5 倍设置来自同一数据的临时校准。现有证据不足以将问题全部归咎于 Reference 的物理模型，也不能宣称固定设置已通过独立校验。
