# 单 GP 与 LLM-Informed：实现、真实小试及审计

日期：2026-10-14；状态：实现完成，软件回归和真实接口接入通过，尚未证明优化收益。

## 本轮实际完成了什么

用户确认后，接入 `BO_Multi_12_20/New_LLMBO` 中区域建议与后验相关性调整的思路。一个六维 ARD Matérn-5/2 GP 学习四倍率平均 RMSE 的标准化对数；LLM 根据已经观察到的参数、误差和截止摘要，提出一个六维参数区域。区域内锚点与候选点的后验相关性决定有上限、随迭代衰减的均值调整，再计算选点 EI。方差、真实训练标签和 GP 核保持原样。

采用原实现的 `heuristic_correlation` 分支；未启用 `lgbo_proposition1`、充电多目标或旧参数分组复合核。六维电芯参数使用归一化坐标；两项扩散系数按 log10 映射，避免原通用舍入方式将小量变成零。实现详情和默认设置见 [方法及复现说明](../llm-informed.md)。

WarmStart、LLM-Informed 分别有开关。新 Informed 不能与旧 GP 分组核同时开启。所有启发式决策保存原 GP 后验、建议、锚点、调整量、原/新 EI、采用或回退原因。非法回复最多进行一次合同修复；接口异常回退并标记运行错误，不补造回复。审计可以离线重算建议、选点和信任更新。

- 完整回归：108 项通过，172.57 秒。
- 检验包括：构造可控 GP 时建议真正改变选点；方差保持不变；调整有界；关闭/弃权时与普通单 GP 一致；非法回复修复；接口失败回退；日志篡改被识别；固定候选验证无需 LLM 凭证。

## 为什么小试没有改善

| BO 次序（候选 ID） | LLM 行为 | 最终决策 |
|---|---|---|
| 1（8） | 区域建议置信度 0.45，低于预设 0.60 | `low_confidence`，使用原 EI |
| 2（9） | 置信度 0.62；合法锚点比例 23/32；调整最大值 0.018729 个标准化 log-J 单位 | 调整前后最优索引均为 7，`same_as_plain` |

第二次并非没有计算引导：置信度、信任值 0.5、锚点一致性约 0.391 共同将有效可靠性降至约 0.121；再经过衰减和相关性后，调整不足以改变候选排序。第一轮则明确拒绝低置信建议。没有为展示“LLM 有作用”而临时降低阈值或增加强度。

|---|---:|---:|---:|---:|---:|

两次 3C 均记录 `event: Minimum voltage [V]`，终端电压约 2.5 V，`solver_error_type=null`。因此这是本次候选在当前 DFN 设置下的覆盖不足，不能解释为 API 未工作或求解器崩溃。按用户已确定规则不外推、不缩短实测评价区间，联合 RMSE 必须留空。这类物理截止记录标记为不可重试；原参数重复仿真不能补出缺失的有效时段，本轮所有规定求解均已执行并留档。

单 GP 只学习完整联合目标，因此两条新记录未增加 GP 标签：训练数仍为 8，拟合一次，之后复用同一模型。部分倍率确有较低误差，但不能替代四倍率目标。最优联合 RMSE 保持 **48.1173866 mV**，未改善；返回的最优参数仍为旧初始点 `[0.73, 0.63, 1.8e-13, 4e-14, 180, 0.3]`，顺序为负/正活性体积分数、负/正固相扩散系数、负/正电导率。

## 专业判断与下一步边界

1. 目前可以使用新模块运行并审计，尚无证据证明它优于单 GP。2 次迭代、0 次实际采用，无法评价区域引导的真实收益，也无法判断 WarmStart 的增益。
2. 此次配置关闭完成概率加权。3C 截止边界限制新有效样本，而完整联合目标 GP 不吸收部分倍率误差；LLM 收到失败摘要也不等于 GP 自动学会可行域。这是当前明确的搜索瓶颈。
3. 先用已保存结果量化建议通过率、引导强度和选点差异，再用同一初始化、同一预算对比单 GP 与 Informed。若调整引导强度，应预先固定实验梯度，不根据单次结果反复调参。
4. 可行性处理可考虑复用现有完成概率模型或基于失败点限制局部搜索，但应作为单独配置和消融因素。不能为了通过率私自改变截止电压、评价终点或 RMSE 定义。本轮未启用这些额外改变。
5. 正式比较仍需多个种子，并分别统计全部筛选成本、API 成本、有效候选率、初始最优值及后续改进。当前没有扩展到 25 次迭代或四组正式消融。
