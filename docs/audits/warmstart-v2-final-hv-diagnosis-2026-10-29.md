# WarmStart v2 最终 HV 未稳定增益：归档诊断（2026-10-28）

## 证据范围

仅重读封存的 `runs/w27` 五种子、十臂真实 DFN–集总热合成档案；本诊断没有新 API、DFN 或 BO 运行。上次 v1/v2 在每个种子共享 16 个实评候选、各选 8 点、各运行 50 轮 ParEGO，目标尺度 `[0.1 V,1 K]`，HV 参考点 `[10,10]`。每个种子是一个配对单位。

## 现象与直接机制

v2 按设计完整保留首层 Pareto 点，但补足名额时以**参数最远距离为第一排序键**；质量 `q`、Pareto 层号只在距离完全相同后决定顺序。因此它允许较差层的远点越过较好层的近点。实现与已批准的 v2 规格一致，这不是已证实的编码公式遗漏。

| 种子 | 首层点数 | v2 入选的第 3 层及更差点数 | v1 八点平均 `q` | v2 八点平均 `q` | 第 10 轮 HV 差 | 第 50 轮 HV 差 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 152325 | 3 | 3 | 0.07960 | 0.09476 | +0.07283 | +0.06019 |
| 235695 | 4 | 3 | 0.06265 | 0.08833 | +0.29505 | −0.01843 |
| 947445 | 4 | 4 | 0.06065 | 0.11223 | +0.01395 | −0.02085 |
| 260437 | 5 | 2 | 0.09430 | 0.10901 | +0.23392 | −0.01235 |
| 299924 | 3 | 4 | 0.08856 | 0.11262 | +0.17133 | +0.11118 |

`q=max(0.5 F_U/0.1,0.5 F_T)+0.05(0.5 F_U/0.1+0.5 F_T)`，越小越好。五组初始 HV 都相同；v2 的八点平均 `q` 在五组中均较大，同时初始参数距离均较大。第 10 轮 HV 差在五组均为正，但第 50 轮只有两组为正；早期优势可能被后期 v1 搜索追上。单凭五组轨迹无法证明较差 `q` 是后期反转的唯一原因，也无法保证任何改版会提高最终 HV。固定参考点下 HV 已接近 100 的上界，报告时须保留逐种子差值与两个 RMSE，不能只报平均 HV。

## 可检验的窄范围修复假设

保留 v1、v2 原有版本和签名；另增独立版本 `pareto_quality_gated_spacefill_v3`。先按 v2 保留 Pareto 首层；设 `q_gate` 为同池 v1 八点中最大的 `q`，后续只在 `q≤q_gate` 的未选完整候选中按 v2 距离优先、同分规则选点。v1 八点始终在门内，所以完整唯一候选不少于 8 时，门内必有足够点。这个门槛由同池固定 v1 基准确定，没有依据五个旧试验结果调整连续超参数。

仅在封存候选池上反事实重选八点，初始参数平均距离和平均 `q` 如下；**没有运行相应的 50 轮 BO**：

| 种子 | v1 距离 / `q` | v2 距离 / `q` | 门控方案距离 / `q` |
| ---: | ---: | ---: | ---: |
| 152325 | 0.2638 / 0.0796 | 0.3558 / 0.0948 | 0.2937 / 0.0893 |
| 235695 | 0.1532 / 0.0626 | 0.2366 / 0.0883 | 0.2056 / 0.0727 |
| 947445 | 0.1911 / 0.0606 | 0.3309 / 0.1122 | 0.2284 / 0.0620 |
| 260437 | 0.2397 / 0.0943 | 0.2853 / 0.1090 | 0.2663 / 0.1000 |
| 299924 | 0.2445 / 0.0886 | 0.3240 / 0.1126 | 0.2975 / 0.0956 |

门控方案在五个旧池中将几何覆盖与平均质量置于 v1/v2 之间。这只支持其选择机制符合预期，不能用来声称最终 HV 增益。任何正式确认都须预注册**新种子**，在同一个新候选池上并行比较 v1、v2、新版本；三个臂共享物理模型、目标尺度、GP/EI、预算和观察数据。保留旧五种子为诊断集，不能与新试验合并为独立确认。
