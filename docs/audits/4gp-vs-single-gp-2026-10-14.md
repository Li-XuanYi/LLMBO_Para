# 4GP 与单 GP：现有真实小试对比

结论：现有 4GP 实验最终 RMSE 略低，但没有证明 4GP 优于单 GP。将预算截到双方都有的前 2 次 BO，两者最优值都没有改善。当前可以确认的差别是部分倍率数据的利用方式；两种配置都受 3C 截止边界限制。

本次仅分析和核验历史文件。新增 DFN 求解 0，新增 API 请求 0，没有改动算法、Prompt 或历史实验。已完成分析 2 组，运行 0，错误 0，待分析 0。

## 1. 真实结果

已逐项验证：两组共享完全相同的 8 个初始化参数，仿真/数据签名、固定参数化指纹、DFN 设置、六参数范围、孔隙约束、四倍率和初始条件均相同。每条有效记录的联合目标已由四个倍率 RMSE 重新计算。

| 项目 | 4GP：2026-10-13 小试 | 单 GP：2026-10-14 小试 |
|---|---:|---:|
| 初始有效点 | 相同 8 点 | 相同 8 点（复用缓存） |
| 初始四倍率平均 RMSE | 48.117387 mV | 48.117387 mV |
| 新增 BO 次数 | 5 | 2 |
| 新候选四倍率全部有效 | 1/5（20%） | 0/2（0%） |
| 最终最优 RMSE | 48.060245 mV | 48.117387 mV |
| 改善量 | 0.057141 mV（0.119%） | 0 |
| 前 2 次 BO 新有效点 | 0/2 | 0/2 |
| 前 2 次 BO 后最优 RMSE | 48.117387 mV | 48.117387 mV |
| 实际新倍率求解 | 20 | 8 |
| 新倍率有效 / 失败 | 13 / 7 | 6 / 2 |
| GP 最终训练标签数 | 12、12、12、9 | 联合目标 8 |

4GP 的唯一改进发生在第 3 次 BO。单 GP 还没有第 3–5 次记录，不能推断它在相同迭代数下会取得什么结果。

## 2. 为什么还不是公平消融

除了预算不同，实际配置也有以下差异：

| 项目 | 4GP | 单 GP |
|---|---|---|
| 随机种子 | 20261011 | 20261014 |
| GP 拟合坐标搜索轮数 | 2 | 20 |
| LLM 机制 | 初始请求倍率参数分组，构建混合核 | 每轮请求区域，选点时调整均值 |
| 训练数据规则 | 每倍率分别使用有效标签 | 仅四倍率全部有效时有联合标签 |
| 采集函数 | 64 次抽样的 Composite EI | 联合误差分布上的解析 EI |
| 完成概率加权 | 关闭 | 关闭 |

单 GP 小试的 LLM-Informed 确实调用了 2 次，但实际改变选点为 0：一次因置信度 0.45 小于 0.60 回退，一次调整后仍选原 EI 最优点。它不是预先设置为关闭 LLM 的纯基线组，不能把该结果伪装成已完成的无 LLM 消融。

4GP 初期使用了非零参数分组核权重，最终全部降为零；训练过程仍受到分组机制影响，不能用最终权重为零来宣布全程都是纯 Matérn 基线。

因此，前两次预算相同的比较也只是描述性比较，并未控制种子、拟合预算和 LLM 因素。

## 3. 已证实的数据利用差异

两组前两次候选均为前三个倍率有效、3C 无效。检查 `models/after-000010.json` 得到：

- 4GP：前三个倍率分别从 8 条增加到 10 条；3C 仍为 8 条。
- 单 GP：联合 RMSE 不存在，仍为 8 条。

单 GP 的新增记录并非被删除，LLM 也能收到失败摘要；但这些记录没有完整联合目标，不能直接作为其回归标签。因此，4GP 在当前“部分倍率成功”场景下确实能让部分模型继续学习。这个信息利用优势尚不能量化为最优误差优势，因为唯一改善还受不同候选池和拟合设置影响。

反过来，单 GP 直接学习最终要优化的平均 RMSE，模型和选点更简洁。当前单 GP 使用解析 EI，去除了采集积分的抽样误差。4GP 的 Composite EI 对四个 GP 分别独立抽样再平均，未显式建模倍率之间的后验相关性；这也是两种统计模型的区别，但本次没有预测校准验证，不能声称它已导致某一组更好或更差。

两种配置每评价一个候选都要执行四条 DFN 曲线。单 GP 不意味着只做一次 DFN。

## 5. 如何得到可归因的结论

建议下一步先固定相同初始化、成对种子、每组 25 次 BO、GP 拟合 20 轮、相同候选策略、固定 DFN 与评价规则，并关闭两种 LLM 增强来比较代理结构。

要区分结构与数据利用，最清楚的三项配置是：

1. 单 GP，完整联合标签。
2. 4GP，各模型只使用四倍率全部成功的候选；与第一项比较代理结构。
3. 4GP，允许每倍率有效标签；与第二项比较部分数据的额外价值。

每项保留同样的完整目标评价，失败不编造 RMSE；使用多个成对种子，报告改进曲线、有效候选率、总仿真/API/时间成本。完成概率策略应所有组一致，若要改变则单列实验设置。验证基础代理后，再加入 LLM-Informed 判断它的独立贡献。本次没有启动这些新实验。
