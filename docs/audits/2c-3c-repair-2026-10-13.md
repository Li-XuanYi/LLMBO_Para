# 2C / 3C 提前截止诊断与修复验证（2026-10-13）

本轮已恢复并验证一套能在完整实测时间轴上计算四倍率 RMSE 的配置。2C 的主要阻碍可以通过现有六参数调整消除；3C 在本轮所有原始电解液对照中都发生严重浓差极化，必须把固定设置与六个辨识参数一起核查。复用此前已批准的电解液扩散系数乘数 1.5 后，已有辨识参数可完成四倍率仿真。

## 2. 原因：2C 和 3C 不能混为一谈

**2C：原始候选的固相传输/极化设置不合适，不是已经证明整个六参数空间无解。**

本轮边界合法的近原始点 `[0.75,0.665,3.3e-14,4e-15,215,0.2]` 在 1703.246 s 触发最小电压事件，而实测持续 1713 s。该点只把原始 Chen2020 的正极电导率 0.18 改为用户范围内的 0.2，图中明确标记；前一轮完全原始点的结果是 1703.074 s。

保持电解液乘数为 1.0，仅将六参数改为受控传输点 `[0.75,0.665,3.3e-13,4e-14,215,0.4]`，2C 已能覆盖 1713 s，RMSE 为 **32.440 mV**。这直接说明“2C 不能拟合”不能归因于 DFN 模型类型或 RMSE 规则。该试验同时改变固相扩散率和正极电导率，不能仅凭它分离各参数的独立贡献。

**3C：固定电解液传输与该高倍率数据的匹配是主要瓶颈。**

使用同一受控传输点，原始电解液设置只持续到 **789.276 s**；只修改 `Electrolyte diffusivity [m2.s-1]` 为原函数的 1.5 倍，就能覆盖 **1138 s**。已有辨识点也表现出相同因果方向：乘数 1.0 时在 **736.673 s** 截止；乘数 1.5 时覆盖完整 1138 s。

同一辨识点、同一 3C 放电时刻 700 s 的内部状态对照：

| 设置 | 电解液最低浓度 mol/m³ | 浓差过电势 V |
|---|---:|---:|
| 原始电解液 ×1.0 | 约 0（数值输出 -0.048） | -0.315667 |
| 校准电解液 ×1.5 | 118.071 | -0.082009 |

接近零浓度时的小负值是离散数值输出，不能解释为物理上的负浓度，也不能把耗尽后的轨迹当作可靠材料行为。本轮采用内部状态来诊断原始候选为何失效；这些失败曲线未获得完整 RMSE，也未用于伪造 GP 标签。校准后的辨识点在 60 网格下，3C 全时域最低电解液浓度为 **53.060 mol/m³**，没有该耗尽现象。

六个辨识参数里的两个扩散系数对应 `Negative/Positive particle diffusivity`，即颗粒内固相扩散；电解液扩散是另一个固定参数。只优化六参数，并不会直接改变电解液扩散函数。DFN 的电解液质量守恒和电流方程分别包含电解液扩散、浓度梯度、离子电导等项，电压也受到多个过电势共同影响。参见 [PyBaMM DFN 方程](https://docs.pybamm.org/en/v25.10.0/source/examples/notebooks/models/DFN.html) 和 [电压分量定义](https://docs.pybamm.org/en/v25.10.0/source/examples/notebooks/plotting/plot-voltage-components.html)。

这是对本轮受控案例的诊断，不构成对整个连续六维参数空间不可行性的证明；也不能单凭这些曲线认定真实电池电解液扩散系数恰好就是原值的 1.5 倍。

## 4. 剩余误差与后续科研判断

**现在能够完整仿真和评分，但还不能称作高精度全曲线拟合。**

60 网格时，2C 最后 20% 时域 RMSE 为 **52.271 mV**，末点偏高 **204.742 mV**；3C 最后 20% 时域 RMSE 为 **127.263 mV**。3C 后段电压下降仍早于实测，低倍率末端下降又偏晚。这些是曲线形状和跨倍率折中的具体证据，不能用“LLM 随机性”解释，也不能只看全程平均 RMSE 而忽略。

接下来需要依次检查，而不宜直接再增加 LLM 调用次数：

1. **核对工况元数据。** I 列为空，需要真实电流/容量标定。T 列 2C 从约 23.6 升到 44.5，而 3C 约为 25 到 24.6，温度含义、单位、测点和是否控温仍未明确。当前无法把它们当作已确认的电芯温度直接驱动模型，也不能据此擅自改变 3C 温度。
2. **验证固定参数的跨倍率一致性。** 同型号外形不能保证 Chen2020 的 OCV、几何、初始锂库存、反应动力学、热条件与本试样完全一致。乘数 1.5 可以补偿多个缺失因素，尚不可作为真实电解液性质定论。新增待辨识参数前应检查敏感性、相关性和可辨识性。
3. **用当前可行点进行六参数收敛对照。** 若继续优化，可在现有严格目标下用确定性局部求精或更充分的 BO 与当前结果比较，分清“优化预算不足”和“固定模型失配”；所有代价需单独计数。这一轮没有实施新的参数搜索，也没有证明当前参数全局最优。
4. **独立验证后再做算法结论。** 所有当前曲线均参与过固定设置校准及参数筛选，属于同数据回放。若后续为评价 LLM 方法优势，应先冻结校准参数，在统一模型与评价规则下运行多随机种子，并补充独立工况/重复电芯验证。
