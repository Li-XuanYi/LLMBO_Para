# LLMGP 失效原因、全维长度尺度弱先验实现与离线验证

日期：2026-10-15。范围：用户确认“全维 ARD＋LLM 弱先验，先离线验证”。保留四个 GP、全部六维、0.5C/1C/2C/3C、完整实测时段、禁止外推。本次新增真实 DFN 求解 **0**，新增 BO 迭代 **0**。

## 结论

**接口与数值实现已完成并验证，但本次没有观察到 LLM 带来的额外收益。** 旧实验的 LLM 返回四个空分组，增强实际未启用；本次新接口得到四组全零先验调整，LLM 组再次等同于通用先验组。通用先验减少了长度尺度触边，却没有改善总体预测，概率预测评分还变差。因此不能把“代码跑通”“参数不触边”写成 LLMGP 优势，也不能声称已经降低了真实电压拟合 RMSE。

## 1. 旧 LLMGP 为什么没有效果

核查对象：`runs/gp-matched-pilots/20261015T113301Z_18c528dbb082_296c6b74`。

- 原始 API 响应明确为四个倍率各返回 `[]`，校验状态是 `abstained / explicit_empty_group`。这是模型实际输出，不是解析器删掉了分组，也不是接口调用失败。
- 两组随后都使用全六维核、分组权重为零，五次候选、预测和仿真结果完全一致。共同的最好四倍率平均电压 RMSE 从 **44.941345 mV** 降到 **44.724748 mV**。这次完全相同的轨迹不能证明“一个真正启用的 LLM 增强核不如普通 GP”。
- 原提示词同时要求提出子集、谨慎解释证据，并允许弃权；请求只提供八个完整初始点，未提供同时已有的四个部分有效候选。建议仅在初始化请求一次，后面没有更新。样本局部集中、请求信息不全和允许弃权共同提供了一条始终回到普通 GP 的路径。**不能从空响应还原模型内部原因**；上述是可检查的机制及合理解释。
- 旧普通核本来就是**全六维 ARD Matérn-5/2**。若把分组改成全部六维，因为子核和主核共享长度尺度，两者相同，混合仍等于原核。因此“允许六维分组”本身不能形成增强。
- 初始 24 个长度尺度中 14 个触及 `[0.03, 8]` 边界；初始样本集中且相关，弱识别值得检查。但旧实验全部已选拟合都达到坐标步长容差，不能继续沿用早期“只拟合两轮”的诊断。坐标收敛也不保证全局最优或统计识别充分。

具体审计证据：`bo-repair-work/20261015_llmgp_literature/mechanism-evidence.json`；旧完整报告：`docs/audits/llmgp-matched-5bo-2026-10-15.md`。

## 2. 文献依据与适用边界

1. Hvarfner 等，**Vanilla Bayesian Optimization Performs Great in High Dimensions**，ICML 2024：通过维度相关长度尺度先验约束全维 GP 的函数复杂度，提供了保留全部变量、调整 GP 先验的依据。本文任务只有六维，且初始化局部集中；不能把高维基准收益直接迁移为电池任务的效果保证。[论文](https://proceedings.mlr.press/v235/hvarfner24a.html)
2. Xu 等，**Standard Gaussian Process is All You Need for High-Dimensional Bayesian Optimization**，ICLR 2025：研究全维 GP 的长度尺度初始化与拟合问题。我们的六维、坐标搜索与其高维梯度问题不同；目前初始核相关性的中位数约 0.30–0.87，没有足够证据归因于高维协方差塌缩。[论文](https://openreview.net/pdf?id=kX8h23UG6v)
3. Papenmeier 等，**Understanding High-Dimensional Bayesian Optimization**，ICML 2025：显示恰当训练的 MLE 也可表现很好。因此必须保留相同拟合预算的 MLE 对照，不能预设 MAP 必然更优。[论文](https://proceedings.mlr.press/v267/papenmeier25a.html)
4. **Adaptive Kernel Design for Bayesian Optimization Is a Piece of CAKE with LLMs**，NeurIPS 2025：LLM 生成核假设，再通过拟合与数值评价筛选。它支持“提出可检验假设”的研究方向，不等同于本次弱先验实现。[论文](https://arxiv.org/abs/2509.17998)

逐篇方法与适用性核查已保存：`bo-repair-work/20261015_llmgp_literature/full-dimensional-gp-primary-evidence.md`。

## 3. 具体实现

保留四个全六维 GP，各自拟合一个倍率的标准化 `log(RMSE)`。LLM 现在可以为每个倍率的六个输入维度给出长度尺度先验位置调整：

\[
\ell_{r,j}\sim\operatorname{LogNormal}(\mu_0+\delta_{r,j},\sqrt3),\qquad
\mu_0=\sqrt2+\tfrac12\log6,\qquad |\delta_{r,j}|\leq\log2.
\]

- 先验条件化在原搜索范围 `[0.03,8]`。LLM 最多把每一维先验的中位数/众数乘以 0.5–2，不能改变方差、物理参数、噪声边界、目标或有效性规则。数值 GP 继续学习所有长度尺度、幅度与噪声。
- 使用原坐标优化器，最大化真实边际对数似然与长度尺度对数先验之和。密度定义在实际长度尺度上，明确包含 `-log(ell)` 和截断归一化；在对数坐标搜索不意味着改变密度域。真实似然与 MAP 目标分别保存。
- 六维基础先验的众数约 **0.502**，中位数约 **10.075**。原论文先验在上限 8 以上有约 **55.3%** 的质量；本次保留原超参数边界，属于**有截断的适配方案，不是原论文逐项复现**。幅度与噪声也继续按本项目方式学习。
- LLM 输入为八个完整候选加四个部分有效候选的参数、有效单倍率 RMSE、残差和截止摘要。曲线与 XLSX 不发送；五个后续验证候选不发送。无效倍率不被伪造为大 RMSE。
- 允许明确的中性零调整；最多一次请求加一次格式修复。本次一次成功，没有为追求非零输出再次请求。由于 LLM 看到训练标签，这属于**数据依赖的弱正则/经验先验**，不应宣称为独立先验下的严格贝叶斯推断。
- 新功能为可选接口与离线工具，尚未替换正在使用的 BO 默认配置。默认无先验分支通过改动前数值快照回归，旧算法行为保留。

## 4. 离线对照设计

三组分别为：无先验 MLE、无 LLM 的通用 MAP、LLM 调整 MAP。三组共用每一步之前的训练数据、输出变换、候选池、完成概率、MC 随机数与选择规则；每次拟合均从长度尺度 **0.1/0.35/1.0** 三个初值出发，各最多 **320** 轮，按各自训练目标选出最优初值。只在各组内部比较自身拟合目标，**不跨不同先验比较 MAP 数值来判优**。

初始有效训练数量为 **12/12/12/8**。按旧轨迹逐步预测五个后续候选；之前实际观测可以进入下一步训练，当前及未来结果不进入。验证有 **14 条独特的有效倍率标签**：前三倍率各 4 条、3C 仅 2 条。四倍率之间及时间上都不独立。两组旧轨迹完全相同，因此只取一条轨迹，不重复计数。

本次 MLE 使用相同三起点重拟合，区别于旧报告单起点 MLE，所以其总体预测 MAE 为 5.867 mV，而旧报告约 6.055 mV；这部分差别属于共同拟合设置，不能记到 LLM 头上。

## 5. 实际结果

下表是 **GP 预测“电压拟合 RMSE”的平均绝对误差**，不是重新得到的电压曲线 RMSE。越小越好。

| 倍率 | 有效标签数 | MLE，mV | 通用 MAP，mV | LLM MAP，mV |
|---|---:|---:|---:|---:|
| 0.5C | 4 | 4.943 | 5.195 | 5.195 |
| 1C | 4 | 4.496 | 4.073 | 4.073 |
| 2C | 4 | 8.882 | 9.177 | 9.177 |
| 3C | 2 | 4.429 | 4.338 | 4.338 |
| 合并，按有效标签微平均 | 14 | **5.867** | **5.890** | **5.890** |

- LLM 的 24 个调整全部为零，因此 LLM MAP 与通用 MAP 的先验、模型、预测与选点一致。这次没有独立的 LLM 增益。原始回复解释了局部训练点相关、低倍率误差范围窄、3C 完整标签少；其中列出的 RMSE 范围与保存数据一致。它关于“不同变换不可直接比较”的表述不能直接视为数学结论：这些输入已经归一化，核距离在该坐标系中是定义良好的。
- 5 个训练快照、四倍率共 120 个长度尺度位置中，触边计数从 MLE 的 **41** 降到 MAP 的 **2**。重复快照计数只是状态诊断，不是 120 次独立实验。触边减少没有转化为总体预测收益。
- 三组名义 95% 预测区间均只覆盖 **9/14=64.3%**。样本少，不能作精确校准结论，但明显没有出现已验证的校准提升。
- 标准化 log 目标上的平均负对数预测密度（越低越好）为 **12.381 → 27.696**，先验组更差。具体集中在第一步 0.5C：真实 RMSE **55.512 mV**，MAP 预测 **46.203 mV**，95% 区间只有 **45.416–47.004 mV**；MLE 区间 **45.269–49.124 mV** 也未覆盖，但较宽。该点说明平滑正则可能在局部未见变化上过度自信，而非“随机性”解释。
- 通用 MAP 与 MLE 在 5 个旧候选池中有 **2 次**选择不同；LLM MAP 与通用 MAP 为 **0 次**。替代候选没有仿真结果，不能据此声称优化终值更好或更差。
- 一次重放实际计算 **108 个起点拟合**，因两 MAP 组相同而缓存复用；其中 **107** 个达到步长容差，一个未入选的初值耗尽 320 轮。最终被选模型全部达到容差，仍不能宣称全局最优。重放约 **24.5 秒**。

## 6. 科研判断与下一步建议

当前证据指向两个不同问题：**LLM 没有提供区别于基线的建议**，以及**通用先验虽然稳定了参数，却未改善预测**。后一个问题不能由更积极的提示词自动修复。新提示词强调谨慎、相关性与中性选项，可能促使模型保守；现有局部数据也确实不支持可靠的逐维识别。只有后续对照才能量化两者贡献，不能仅凭一次回复归责于模型能力或提示词。

建议先利用工况完全一致、来源可核验且分布更广的历史数据检查 GP 的预测与不确定性，重点检查噪声估计、局部曲率和外推位置。若用交叉验证筛先验，LLM 的数据摘要也必须限于每个训练折，避免模型提前看见验证标签。可以让 LLM 产生少量有解释的竞争假设并由数值验证选择，同时保留中性基线；不能强制非零并把“参数发生改变”当作优势。

上述是下一阶段建议，本次未执行新 Prompt 对照、额外 DFN 或新 25 轮实验。现有 **44.724748 mV** 的真实电压结果没有被本次离线实验刷新。工程实现可运行，科研有效性仍未获得支持。
