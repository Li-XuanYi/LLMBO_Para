# Reference 论文、Notebook 与当前四倍率 RMSE：对照审查

日期：2026-10-14。任务：阅读用户提供的论文，解释 RMSE 水平和优化停滞；本轮不改变算法、物理设定或实验目标，不新增 DFN/API 调用。分析和复算文件单独保存，不覆盖历史实验。

## 结论

**现在不能把“48 mV 左右且几轮不变”解释成 LLM 无效，或 DFN 的精度下限。** 论文报告的误差本来也是几十毫伏至约百毫伏；我们当前与论文、Reference Notebook 的评价协议和算法实现并不完全相同。最近两点没有产生完整四倍率有效结果，故完整目标没有更新。此外，最近几个小试从同一八点初始化分别启动，并不是在连续累积同一次优化；项目里至少已经保存一个相同仿真设置、相同数据下的 **45.473608 mV** 有效结果。

高误差有实际的曲线来源：当前八点中最佳候选的低倍率末端下降明显偏迟。停滞则有直接的流程来源：3C 截止约束使新候选无法计为完整成功、成功样本不足，以及诊断小试反复重启而非持续推进。两者需要分别处理。

此前汇报将 48.117 mV 作为“小试最优”，没有充分并列说明另有 45.474 mV 历史可行成绩，容易造成已在该精度长期收敛的印象；本报告明确纠正这一点。45.474 mV 是已验证的可达成绩，也不代表全局最优。

### 表格内部需要核对的事项

表 4 的同一行同时写出：0.5C RMSE=0.0249 V、MAE=0.0297 V；1C 为 0.049/0.059 V；2C 为 0.063/0.064 V。对相同残差、相同非负归一化权重，必有 `MAE <= RMSE`，这些数字不满足。多行出现类似现象。

本轮已查看原 PDF 高清表格，而非仅依靠文本提取，因此不能用 OCR 错位直接消除该问题。可能是表头、转录、统计范围或指标计算不一致；应获得作者的残差和计算脚本后判断，不能据此指控数据不实，也不能无条件把表中每个数作为复现验收值。

初始化预算也有不一致：第 5 页 3.5 节提到 60 个参数向量，第 6 页表 2 写 15 个初始样本；现有 Notebook 是 10 个初始样本、10 次优化。论文还列出每轮 15 个候选。候选生成数不一定等于 DFN 评价数，不能只比较“50 轮”和“25 轮”而忽略真实仿真总成本。

## 2. Reference Notebook 与当前评分并不相同

已核对 `Reference/LLAMBO-master/P2D.ipynb` 的代码单元，未执行 Notebook，也未将其中的指令当作用户指令。

| 项目 | 现有 Reference Notebook | 当前四倍率流程 |
|---|---|---|
| 模型 | `pybamm.lithium_ion.DFN()`，Chen2020 | 同一 DFN/P2D 模型家族，Reference-Chen2020 参数工厂 |
| 优化仿真 | 核心函数写死 1C、截止 2.5 V | 0.5C、1C、2C、3C 共用六个参数 |
| 比较时间网格 | 把实测插值到仿真实际时间点 | 把仿真对齐到全部实测时间点 |
| 提前截止 | 对已经跑出的短曲线仍算 MSE | 未覆盖完整实测时段，联合目标无效 |
| 外推 | `fill_value="extrapolate"` | 禁止外推 |
| 当前传入固定电解液扩散倍率 | Notebook 未显式加入我们的校准 | 1.5，来自此前高倍率修复 |
| 初始状态 | `sim.solve()`，未显式传 `initial_soc` | 保留参数集初始浓度，未强制重新映射 SOC |

**相同参数在这两套评分中可能一边得到有限误差、一边被判不可行。** 提前截止后被省略的末段可能恰好是高误差段；仿真自适应时间网格也改变了误差权重。这些是 Notebook 的可观察行为，不等于已证明论文最终实验采用同一段代码和评分规则。

我们坚持完整时段并非指标计算错误，而是此前用户明确选择的研究目标。不能通过丢掉难拟合的末段、降低截止电压或外推来制造“改进”。若做 Reference 原规则的诊断，必须另列指标，不能替换主目标。

DFN 就是这里常称的 P2D 电化学模型。将名称换成 P2D 不会消除差异；需要核对固定参数、初始状态、求解与评价协议。模型可参照 [PyBaMM 官方 DFN 文档](https://docs.pybamm.org/en/v25.10.0/source/examples/notebooks/models/DFN.html)。

### Notebook 本身存在的工程问题

以下仅说明不能把该 Notebook 不经审查直接当作复现标准，不能推断作者论文运行时一定触发了这些问题：

- 评价返回 `score=-mse`，异常返回 `-1e6`，但任务设置 `lower_is_better=True`。Reference 的优化器因此按越小越好处理内部观测；结尾又用 `argmax` 挑最优，优化方向不一致。我们当前最小化正 RMSE，没有沿用该符号问题。
- 核心评价访问全局 `time_data/voltage_ref`；前面一个单元把它们设为 3C，`main()` 内又读局部 1C 变量，存在依赖执行顺序的风险。另有后处理 2C 仿真与 1C 数据混用的代码。不能据 Notebook 展示图标题认定实际工况。
- Notebook 使用 `sm_mode="generative"`，走 LLM 生成式代理路径；它并不是论文公式 (5) 中“电压灵敏度梯度耦合的 GP 核”的直接实现。
- 该路径构造生成式代理时没有转交 Notebook 中的 `chat_engine`；库中的标准接口调用写死 `gpt-3.5-turbo`。仅修改 Notebook 的模型名称不能证明所有组件都更换了模型。
- 初始化函数是随机生成；Notebook 部分初始化范围上限为 1.0，而论文列出的对应上限为 0.8。

原 Notebook 中包含历史硬编码凭据，本轮保存的代码摘录已脱敏。原 Notebook 未修改；报告不复制凭据，也不使用该凭据调用服务。

## 5. 为什么“总是不改善”

最近完成的小试是“复用同一八点＋两次新 BO”。新增两点的 3C 分别在 1128.824 s、1127.037 s 触发最低电压，要求为 1138 s；差约 9.18 s、10.96 s。是正常截止事件，不是求解器异常。前一个候选前三倍率 RMSE 为 41.518/35.025/40.510 mV，但缺少完整 3C，不能形成更好的合法四倍率目标。

两点预测完成概率为 0.126 和 0.405。`EI × 完成概率` 仍可能选择低概率但高预期改善的点；它不是完整成功的保证。最近结果直接说明短预算内没有得到完整改进，不足以证明分类器一定失准或 LLM 无效。把 MC 采样由 64 增至 1024/16384 的离线重放未改变这两个候选池的选择，本例也不能归因于抽样抖动。

截至该小试结束，四个 RMSE GP 标签数为 32/25/17/8，最困难的 3C 仍只有八个有效样本。已经接入失败筛选点的其他倍率观测，并增加 GP 拟合预算；但这些改进不会自动产生新的 3C 标签，训练停止条件也不是预测准确或全局最优的证明。

更重要的是，本轮与此前小试分别启动，未将所有历史 BO 结果累积成一个持续优化序列。较早 `20261013T135909Z_ed9ec91493cd_83f20943` 已保存：

- 完整四倍率平均 RMSE = **45.473608251 mV**；
- 参数 = `[0.7292787398454192, 0.6285912174582646, 3.1425645232092747e-13, 2.3752720366650134e-14, 257.4680963524171, 0.23196407392502486]`；

## 6. 论文的 LLM 增强与当前方法不是同一实现

论文第 4–5 页描述：WarmStart；带电压参数灵敏度耦合项的 GP 核；动态调整的 LLM 采集权重和候选建议。当前四 GP 路径使用每倍率 Matérn-5/2 全维核与 LLM 子空间分组核的混合；完成概率由历史成功/失败训练的逻辑模型给出。它既不是论文的电压梯度耦合核，也不是论文的 LLM 采集权重。

最新小试 `llm_informed.enabled=false`；单 GP 的 LLM_Informed 分支已经实现，不代表当前四 GP 运行启用了它。最新运行有一次 LLM 参数分组调用；初始化复用历史 LLM 八点。不能因论文的完整方案有提升，就推定当前这两个组件的实现一定能获得相同收益。

因此“论文 LLM 有效、我们没有收益”的差异，首先要求方法和实验协议对齐。本轮没有支持“换更强 LLM 就会解决”的证据，也没有支持“LLM 必然无效”的证据。

## 7. 建议顺序：先消除复现歧义，再检验方法增益

1. **固定参考检查点。** 优先用论文表 3 的 LLMBO-3.5 参数做 1C、再四倍率验证，同时单列 Notebook 原规则与完整时段规则的诊断指标。原主目标保持不变。对表 3 中与当前孔隙率冲突的其他点，先取得作者固定参数/解释，不能偷偷放宽约束。
2. **定位低倍率末端与高倍率截止之间的取舍。** 先核实初始状态、实测电流、温度记录及固定孔隙率；在物理允许范围内做少量、可解释的单因素或剖面检查。如果证据支持修改固定参数，另开配置并说明其校准数据，避免把同一曲线既校准又当独立验证。
3. **做连续优化能力诊断。** 在仿真签名一致的前提下汇总可用历史观测，从至少 45.474 mV 的已知水平继续检验非 LLM 基线和选点可行性；完整记录历史成本、失败截止和每倍率学习情况。这是历史数据续跑诊断，不混入原固定初始化消融排名。
4. **再做公平 LLM 消融。** 固定物理模型、评价、GP 拟合预算、候选空间和总 DFN 成本，多随机种子比较达到同一误差所需成本、可行率、完整 best-so-far 和最终误差。不能只比较相同名义 BO 轮数；WarmStart 筛选成本必须算入。LLM 分组与概率处理的变化需分别控制。

本轮仅提出上述验证方案，未擅自修改方法或新增仿真。当前分析已完成；新增优化任务 0，新增 DFN 0，新增 API 0，运行 0、待运行 0，无需 ETA。
