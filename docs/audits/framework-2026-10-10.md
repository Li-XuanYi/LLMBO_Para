## 已接通的流程

1. JSON 配置集中预检：收集缺项、未知键、单位、参数域、逐倍率初始条件、数据映射、PyBaMM 版本、求解器、网格和资源设置；不执行科研组工厂或 API。
2. 六参数合法性、归一化、物理约束、LLM 候选筛选与 Sobol 补足；初始点及来源归档。
3. 同一候选在四倍率分别求解，固定网格对齐，逐倍率 RMSE 后等权平均得到 J；失败不伪造标签，四倍率均尝试。
4. 一次初始后参数组建议；四个完整六维 GP、冻结的对数 RMSE 标准化、全维/子集 Matérn-5/2 混合核和可学习的 0～0.8 权重。
5. Monte Carlo Composite EI 选择一个候选，再执行四倍率求解；保存候选池、种子、分数、选择和 GP 状态。
6. 唯一运行目录、不可覆盖记录、源码/输入/参数化快照、状态与速度/ETA、独立结果复算，以及新目录失败补跑。

CLI 提供 validate-config、inspect-workbook、preflight、smoke、run、demo、status、audit-run 和 retry-failed。命令与使用顺序见 [README](../../README.md)。LLM 是自定义 HTTPS 结构化服务契约，仅两种请求；真实服务尚未调用。

## 已复现并修复的问题

在变更前源码上执行 8 个审计用例，1 个通过、7 个失败；失败日志完整保留于 baseline-regressions.txt。这些失败是刻意对旧实现进行回归检验的证据，并非当前遗留错误。

| 问题 | 影响 | 修复与验证 |
|---|---|---|
| 请求 2 个初始 Sobol 点却消耗 32 个序列位置 | 初始与后续候选序列偏离记录的分配 | 只消耗实际生成的点；核对序列位置、分批一致性和独立参考 |
| 混合权重不能取 0 | 数据无法完全否定不合适的参数组先验 | 直接有界优化标量，测试 0 和 0.8 两端点 |
| 覆盖不足的失败仿真没有保留原曲线 | 无法定位早停和比较区间错误 | 校验前保留原数组，失败记录含曲线、异常、调用次数与耗时 |
| 命名 I 列时兼容模式可绕过电流符号要求 | 可能向模型传入反号放电电流 | 显式要求放电符号；桥接按确认的符号转换 |
| 部分缺失的电流被额定电流替换 | 实测驱动可能被悄悄改写 | 只允许整列缺失时使用获准兼容假设；部分缺失直接拒绝 |
| 残差摘要可嵌套原始曲线 | 原始实验记录可能进入 LLM 请求 | 白名单只允许有限标量统计量；传输前拒绝数组与未知字段 |
| 同一优化器能再次运行并追加历史 | 多次实验记录混合，预算与变换不可靠 | 单实例只运行一次，每次新建归档 |

接口审计还补齐了配置到真实仿真条件的连接、实验全量源码和 GP/EI 证据、参数工厂孔隙率一致性、失败补跑以及状态计数。此前已修复的输出标准化重新拟合问题继续保留回归测试。所有错误及预防措施见 [mistakes.md](../mistakes.md)。
