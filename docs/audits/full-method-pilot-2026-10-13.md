## 实际初始化和成本

WarmStart 每批请求 20 个候选，再由 LLM 选择候选进行真实四倍率验证；取得两个有效点后通过小试检查，再继续到八个。没有使用历史最优点或历史八点集合。

| LLM 生成批次 / 原始候选 | 4 / 80 |
| LLM 选择请求 | 12 |
| 解析、重复或必要物理约束筛除 | 25 |

达到八个有效点即结束筛选，未要求把所有生成候选全部求解。初始点产生速度约 1.82 个/分钟，有效率为 8/47；这是一轮实现成本记录，不是 WarmStart 优越性的证据。

接着完成 5 次序贯 BO，新增 20 次倍率求解。5 个候选中 1 个四倍率全部有效、4 个至少有一个倍率提前截止。整个新实验共评价 **52 个真实候选、208 次倍率仿真**；优化器里的八个初始缓存记录来自本轮筛选，不重复计费或计入实际求解。

208 次倍率仿真中有 **119 次最小电压事件导致完整时域不满足**（筛选 112、BO 7），没有求解器异常。这些失败都保留真实终止信息和部分曲线，未赋予虚假完整 RMSE；满足完整时域的倍率数据按现有每倍率训练规则使用。

实验相关 Chat 请求 17 次：4 次生成、12 次选择、1 次 GP 分组；另有 1 次最小鉴权连通性请求，总共 18 次，均 HTTP 200，返回用量累计 **73,804 token**。此前还有 1 次不带生产请求头的公开模型 GET 返回 403，单独记在准备记录，未发送凭据或电池数据；不能把它当作本轮 Chat 失败。

成功控制器运行耗时 **312.21 s**（约 5.2 分钟，不含前期准备和最终绘图）。已完成 1 组、运行 0、程序错误 0、待运行 0；深度审计通过，最终 CSV 独立重算误差一致。

## GP LLM 是否实际参与

LLM 返回了非空的四倍率参数子集，严格合同校验通过：

| 倍率 | LLM 提议子集 |
|---|---|
| 0.5C | ε_p、D_s,p、σ_p |
| 1C | ε_p、D_s,p、σ_p |
| 2C | ε_p、D_s,p |
| 3C | ε_p、D_s,n、σ_p |

数值 GP 在六维基核与子集核之间学习混合权重；LLM 提议被接受不意味着该子集必然获得非零权重。实际用于每次 BO 选点的权重如下：

| BO 选点序号 | 0.5C λ | 1C λ | 2C λ | 3C λ |
|---|---:|---:|---:|---:|
| 1 | 0.2 | 0.2 | 0.4 | 0 |
| 2 | 0.4 | 0 | 0.4 | 0 |
| 3 | 0 | 0 | 0.2 | 0 |
| 4 | 0 | 0 | 0.2 | 0 |
| 5 | 0 | 0 | 0 | 0 |

最终更新后的四倍率权重也全部为 0。因此 GP LLM 的调用、校验、核构建与初期参与均已证实；其最终贡献较弱，3C 的子集核全程未获得正权重。权重变为零是当前训练数据与数值拟合结果，不能解读为组件没搭建，也不能据此证明 LLM 子集在物理上错误。

## 结论的范围

本轮足以验证“我们的方法能从新 LLM 初始建议走完整个辨识闭环”。5 次 BO 的改进很小、4/5 个新候选不可行，说明还需要关注可行区域选点与固定模型的拟合上限。不能用这一组小试证明 LLM 优于无 LLM，也不能作统计显著性判断。若进行效果评价，应沿用冻结的仿真设置开展配对消融、多随机种子和独立验证；这一轮没有自动扩大到正式实验。
