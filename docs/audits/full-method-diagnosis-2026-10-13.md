# 完整方法小试效果不佳：执行证据与原因排序

本轮只分析已保存数据，不修改生产代码、Prompt、配置或历史结果。新增 DFN 求解 0，新增 API 调用 0。离线 GP 重拟合与采集函数积分敏感性检查均单独归档，不作为新的 BO 实验成绩。

最明确的原因是 **完整时域可行性没有进入选点、筛选数据没有充分传给 BO、GP 数值训练预算偏小**。当前证据不足以把主要责任归给 LLM 能力或 API 模型。端电压曲线仍有系统性残差，固定物理设置失配也是待验证因素，但尚未证明六参数已经优化到最优或确定了模型误差下限。

## 1. 5 次 BO 只有一次能完整评分，主因不是全局点过多

| BO 序号 | 来源 | 结果 | 3C 截止 s / 所需 1138 s | 与要求的差距 |
|---|---|---|---:|---:|
| 1 | 局部 | 仅 3C 不完整 | 1137.326709 | 少 0.673291 s |
| 2 | 局部 | 仅 3C 不完整 | 1124.353891 | 少 13.646109 s |
| 3 | 局部 | 四倍率完整有效 | 覆盖 1138 | 新最佳 J=48.060245 mV |
| 4 | 局部 | 仅 3C 不完整 | 1130.039343 | 少 7.960657 s |
| 5 | 强制全局 | 四倍率均不完整 | 935.437895 | 少 202.562105 s |

前四次确实在局部区域搜索，每轮池中有 48 个局部、16 个全局候选；第 5 次按预定配额必须选全局点。所以“主要被全局点吸引”不适用于这一轮。

实际配置 `feasibility_weighting=false`，5 次选点均使用 `policy=raw_ei`，`p_complete=null`。容量/体积分数预筛只检查必要条件，不能预测 3C 极化导致的提前截止。RMSE 代理只学习完整倍率标签，缺少截止边界模型，预测能改善 RMSE 的点仍可能刚好越过完成时域的边界。四次无效候选仍产生了其他倍率的有效标签，但不能改进完整四倍率最优目标。

局部半径在前两次失败后从 0.02 降到 0.013333，说明适应机制确实执行了；然而第三次成功后第四次又发生局部截止，单靠缩小半径不能替代学习边界。第 5 次全局探索长期可能有价值，但在只有五次预算的小试里占去一次评价，不能据此断言长期全局探索应取消。

严格完整时域是用户已确认的科学目标。不能通过允许外推、放宽截止电压或把差 0.67 s 的候选强行算有效来美化结果。更合适的候选策略是分别建模可行性/截止裕量和有效 RMSE；这符合约束 BO 的基本思路，参见 [Gelbart 等：Bayesian Optimization with Unknown Constraints](https://arxiv.org/abs/1403.5607)。本项目现有完成概率模型尚未在本轮启用，不能声称它已经解决这些失败。

## 2. 筛选算过的数据保存在磁盘上，但没有进入初始 BO

初始化执行 47 个候选，最终导出 `initial-plan.json` 的 `evaluations` 只有 8 个全倍率成功点。39 个失败候选虽然没有完整总目标，其中仍存在以下有效的完整单倍率标签：

| 倍率 | 未进入初始 GP 的有效标签 |
|---|---:|
| 0.5C | 22 |
| 1C | 15 |
| 2C | 7 |
| 3C | 0 |
| 合计 | **44** |

初始 `models/after-000008.json` 显示每个 GP 只有 8 个样本，完成模型为 `not_fitted`。39 个已知失败候选也没有用于训练该模型。当前 `training_data=per_rate` 能利用 BO 阶段的部分倍率成功结果，却没有把筛选阶段这些结果带入初始训练。这是两个阶段之间的信息利用缺口，不能说“历史文件丢了”，也不能说“所有失败数据都已充分使用”。

因此，188 次初始化倍率求解中获取的很多信息并未传递到 BO。特别是 3C，虽然没有被丢弃的有效 RMSE 标签，但有大量提前截止证据，本应帮助判断完成边界。

后续若把全部筛选信息用于 GP/可行性模型，必须把筛选成本及信息量计入算法比较，所有消融组采用一致规则。不能额外使用 47 个候选信息后仍宣称仅有 8 个初始信息点。

## 3. WarmStart 当前优先找可行点，不是对候选质量做完整排序

现有选择 Prompt 明确优先考虑完整时域，再考虑参数空间差异。筛选器取得八个有效点就停止；发送给后续生成的反馈包括已接受参数、失败参数和覆盖时长，却没有把已接受候选的真实 RMSE 作为连续排序奖励反馈。

这使 WarmStart 更接近“带物理先验的可行初始化”。本轮 47 个求解候选只接受 8 个（17.0%），初始最佳 J=48.117 mV；不能假设这样的初始化已经接近最优拟合。

八个有效点的 ε_n 仅在 0.73–0.75，ε_p 在 0.63–0.66；对应用户原始归一化区间的宽度只有 3.33% 和 5%。扩散系数范围相对宽一些，归一化六维平均两两距离 0.351。这样的分布符合可行区域限制，同时使 GP 很难从八点中区分容量参数的影响与其他参数补偿。不能仅凭候选集中就认定 LLM 错误，因为物理可行区域本身也很窄。

## 4. GP LLM 的作用受数据量、核形式和数值训练限制

LLM 为每倍率提出 2–3 参数子集；GP 仍用完整六维输入，学习全维核与子集核的混合权重。LLM 没有直接学习完整电压曲线、生成每步 BO 候选或校正 DFN 方程。它的作用范围较窄，无法补上遗漏的筛选数据或错误的完成概率估计。

本轮初始每个 GP 八条标签，结束时前三个倍率各 12 条、3C 只有 9 条。LLM 分组只在初始阶段调用一次，并未根据后续 BO 数据刷新。子集只是统计建模假设，不等于经验证的真实敏感参数。

实际 GP 每次拟合都从默认长度尺度 0.35 等初始化出发，只做 **2 轮坐标搜索**，核权重步长为 0.2。固定数据、固定分组，在离线诊断中增加到 20 轮得到：

| 训练快照 / 倍率 | 2 轮 λ | 20 轮 λ | 训练边际对数似然增加 |
|---|---:|---:|---:|
| 初始 / 0.5C | 0.2 | 0 | 7.403 |
| 初始 / 1C | 0.2 | 0 | 5.468 |
| 初始 / 2C | 0.4 | 0.8 | 3.152 |
| 初始 / 3C | 0 | 0 | 0.599 |
| 最终 / 0.5C | 0 | 0 | 21.002 |
| 最终 / 1C | 0 | 约 0 | 16.547 |
| 最终 / 2C | 0 | 0 | 5.128 |
| 最终 / 3C | 0 | 0 | 0.681 |

这些变化说明 2 轮训练尚不能视作充分数值优化，部分权重判断也对训练预算敏感。更高训练似然不保证更好的泛化或 BO 效果；本轮没有重新用这些模型选点并仿真。最终 λ=0 可以说明现有拟合未保留子集核，不能单独证明 LLM 提议没有价值，也不能据此强制 λ 非零。

另外，原始 Composite EI 使用 64 次蒙特卡洛抽样。固定已保存 GP 和候选池，改用 4096 次抽样、三个种子离线重算：第 1、3、4、5 次仍选择原候选，第 2 次改变为另一个局部候选。因此蒙特卡洛精度会影响部分接近的排名，但不能把本轮整体结果主要归因于抽样随机性。新选择的候选未做 DFN，不能声称它一定更好。

## 5. 曲线误差是系统性的；RMSE 没有计算错

| 倍率 | 全程 RMSE mV | 最后 10% 时域 RMSE mV | 最后 10% 占全程平方误差 | 末点偏差 mV |
|---|---:|---:|---:|---:|
| 0.5C | 49.356 | 144.613 | 85.8% | +488.834 |
| 1C | 43.567 | 109.680 | 63.2% | +380.271 |
| 2C | 40.031 | 66.582 | 27.6% | +208.102 |
| 3C | 59.287 | 123.964 | 43.4% | +35.346 |

完整 RMSE 及其独立 CSV 重算已通过审计。低倍率平台段拟合较好，末端下降仍偏晚；3C 后段又明显偏低，体现跨倍率折中。×1.5 电解液校准解决了严重提前截止，不等于 OCV、初始状态、动力学及热条件已与实测电池完全一致。

I 列为空，倍率电流仍由 5 Ah 推算；T 列含义/单位/控温方式没有最终确认。固定 Chen2020 设置是否完全适配本电芯仍需核查。上述因素是合理候选解释，不是本轮已经确定的根因。需要充分收敛的六参数优化对照、固定参数敏感性分析和独立工况验证，才能区分剩余误差有多少来自模型、数据工况或搜索不足。

RMSE 是有效评价指标，但单一全程平均不能描述全部曲线形状；可在不改变主目标的前提下同时报告尾段 RMSE、末点偏差与截止时间。直接替换主目标会改变科研问题，不应为获得更好数字而临时修改。

## 6. 后续工作的优先级

1. 衔接筛选与 BO 数据：保留所有候选的真实完整单倍率标签及完成/截止反馈，不制造失败 RMSE。
2. 明确处理完整时域约束，学习完成概率或截止裕量；完成到观测末点的轨迹只说明至少持续到该时刻，不能把它当成实际截止时间。保留严格评分协议。
3. 先验证 GP 数值收敛、预测校准和采集函数稳定性，再讨论是否需要更复杂的 LLM 分组。增加训练轮数后需重新小试，不能用离线训练似然代替真实改进。
4. 在统一成本规则下区分“找八个可行点”与“找八个高质量且有差异的点”，给 WarmStart 提供已测质量反馈；新增机制属于后续实验设计，不是本轮已实现内容。
5. 用固定仿真设置做更充分的优化对照，若系统残差仍稳定存在，再核对工况与固定参数；最后以配对消融、多种子结果评价 LLM 的实际收益。

有关局部搜索与过度探索的讨论可参考 [TuRBO 原始论文](https://proceedings.neurips.cc/paper_files/paper/2019/hash/6c990b7aca7bc7058f5e98ea909e924b-Abstract.html)，但本轮已确认前三个失败都是局部越过完成边界，不能机械地把“改成局部 BO”当作尚未实施的解决方案。
