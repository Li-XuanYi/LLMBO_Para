## 5. RMSE / HV 统计与审计

- 实验单位是独立种子运行，主对照 `n=3`；20 轮是轨迹，不当成 20 个独立重复。
- 完整真实目标对才进入 GP、Pareto 和 HV。每工况保留电压 / 温度有效性、RMSE、归档曲线和同次 solution ID；由曲线独立复算两个总体目标及所有 HV，审计通过才用于比较。
- 主指标为最终 `delta_HV = HV_New - HV_Old`，同时报告逐种子值、均值及 New / Old 相对 Plain 的结果。HV 越大越好；截断在固定参考点之外的贡献按同一规则处理。报告绝对差和相对于固定参考面积 100 的差，不用各臂自己的尺度。
- 每臂按固定均衡标量 `max(0.5*F_U/0.1,0.5*F_T/1)+0.05*(0.5*F_U/0.1+0.5*F_T/1)` 选一个 Pareto 折中参数。平局按规范化参数字典序再 evaluation ID。报告**同一参数**下的 `F_U(mV)`、`F_T(K)`、每倍率 RMSE、完整 Pareto 参数集和逐轮曲线；另列各目标极值，不能拼成不存在的最优参数。
- 记录每轮 Region 请求 / 完成 / 合法 / none / fallback / selection_changed / 实际 HV 改善，区分动作成功与优化增益。所有正负结果保留。
- 不完整主对照、审计失败、源污染或预算耗尽均为 inconclusive，不写“新版变差”或“增益通过”。三种子和一次确认不构成普遍优势或统计显著性证明；60 秒稀疏合成观测不能证明参数唯一可辨识或实测有效。
