## 2. 简化后的唯一主流程

每轮先按当前权重重建真实历史标量标签、标准化、incumbent及GP，冻结上下文；LLM读取该上下文的简洁摘要，直接返回一个归一化六维矩形和置信度，或者弃权；host在区域内生成锚点，计算倾斜均值；使用倾斜均值、原标准差和真实历史incumbent，在**整个原候选池**计算Gaussian EI并选点。

LLM不选择目录ID，不必引用历史证据ID，不要求解释文字。host仍保存实际发送的历史来源，能够审计摘要。保留已有有信息的非初始动态残差，但删除候选目录、eligible名单及复杂的候选竞争说明。

最小动作示意：

```json
{
  "request_id": "<host生成的完整请求绑定>",
  "region": {
    "kind": "region",
    "lb": [0.1, 0.2, 0.1, 0.2, 0.3, 0.2],
    "ub": [0.5, 0.6, 0.7, 0.8, 0.7, 0.8],
    "confidence": 0.65
  }
}
```

上述数值仅展示格式，不是推荐物理参数。坐标的线性/log10变换固定由参数方案确定，不交给LLM推断。lb/ub必须是长度6的有限实数数组，逐维满足0≤lb<ub≤1；confidence为[0,1]内有限实数，布尔值不作为数字接受。弃权仅返回同一 `request_id` 和 `{"kind":"none"}`。不接受额外字段或隐式类型转换。

`request_id`由host对冻结请求及契约版本生成，覆盖参数方案、fit_rates、模型/数据/比较/算法签名、当前权重与尺度、上下文和发送内容；实际实现须明确不参与自身摘要的绑定字段，避免自引用。host验证后从不可变本地上下文恢复完整内部envelope。减少LLM重复抄写不降低签名校验。

## 3. 唯一数学规则

设 \(f_t\) 为本轮线性标准化标量目标的GP，\(A\) 为区域内锚点。固定种子Sobol生成32个区域锚点；按现有物理参数映射过滤非法点，对保留下来的 \(M\) 个点取**均匀权重** \(a_i=1/M\)。过滤前后坐标和数量均归档；没有可行锚点时回退Plain，不扩张或裁剪LLM区域。

使用本轮**潜在函数后验协方差**，令

\[
v=a^\top K_t(A,A)a,\qquad
\lambda=\frac{c}{\sqrt v},\qquad 0\le c\le1.
\]

对最小化问题采用负向指数倾斜：

\[
\widetilde p(f_t)\propto p(f_t\mid D_t)\exp[-\lambda a^\top f_t(A)],
\qquad
\widetilde\mu_t(x)=\mu_t(x)-\frac{c\,K_t(x,A)a}{\sqrt v},
\qquad
\widetilde K_t=K_t.
\]

这是论文最大化写法的符号适配。定义有符号调整 \(\delta=\mu-\widetilde\mu\)。保留后验协方差的正负号；负相关位置允许均值上移，不进行正相关截断。由协方差不等式可得

\[
|\delta(x)|\le c\,\sigma_t(x).
\]

该不确定性界替代人为逐点clip及多因子强度乘积，不新增强度超参数。\(c=0\)精确回到Plain。\(v\le10^{-12}\)、非有限数或无有效锚点时记录原因并回退；显著负方差归类为数值错误。不通过新增噪声或修改协方差掩盖退化。

EI使用同一冻结空间的 \(\widetilde\mu_t,\sigma_t,z_t^{best}\)。incumbent仅来自真实已有观测，不按LLM倾斜重写。候选不必处在LLM矩形内，因为协方差作用可以延伸到区域外。全池最大EI决定选择，确定性同分沿用既有稳定候选身份规则。

## 4. 删除和保留的机制

| 当前Region机制 | 新LGBO策略 |
|---|---|
| host区域目录、固定宽度层级、候选/证据ID选择 | 直接返回有界矩形与confidence |
| EI/不确定性/新颖性混合锚点权重及consistency | 可行Sobol锚点均匀权重 |
| 正相关截断、固定均值上限 | 有符号协方差倾斜，自然界 \(c\sigma\) |
| trust、退火、前12轮关闭、多系数相乘 | 每轮按当前真实历史重新请求并计算；无额外乘子 |
| eligible shortlist、EI差/标准差比门槛 | 不作为新策略的采纳条件 |
| fair_plain_baseline及必须替换Plain的竞争门槛 | 直接取全池倾斜EI最大值；结果可自然仍是Plain |
| JSON/范围/物理/身份/预算/数值检查 | 保留 |

不要求结果一定改变选点；相同点表示本轮倾斜没有改变排序。API失败、未完成JSON、弃权、非法区域及数值退化回退Plain，其余合法动作进入公式。低于0.6不再自动拒绝，而是按实际 \(c\) 产生较弱倾斜。API请求和重试次数只按另行明确的运行协议执行，不因移除策略守卫而无限重试。
