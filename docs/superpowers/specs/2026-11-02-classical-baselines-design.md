# NSGA-II / ParEGO / SMPSO 电热对比协议

用户在四臂五种子50轮完成后要求继续做NSGA-II、ParEGO、PSO对比。沿用直接实施并运行的授权，不重新申请次数或费用额度；本次不调用API。使用实验设计流程先冻结本协议，保留全部正负结果。

## 方法与取舍

- 使用官方jMetalPy固定版本的NSGAII和SMPSO，不自行重写进化或速度公式。PSO明确命名为**SMPSO多目标粒子群**，不把普通单目标PSO静默套上电压目标。jMetalPy版本以独立环境实际安装结果及源码哈希为准。
- NSGA-II用population=16、offspring=1的steady-state配置，与既定外部基线设计一致；SBX概率0.9、分布指数15，多项式变异概率1/6、指数20。不是经典大种群充分预算结果。
- SMPSO swarm=16、crowding-distance leader archive=64，多项式变异概率1/6、指数20；速度限制、边界反弹、学习系数、惯性和扰动频率保持锁定官方实现。按粒子实际评价计数，50个新点只覆盖少数完整swarm轮次，终止可发生于末代中途，不改名为50代。
- ParEGO-16复用现有MOOptimizer、ARD Matérn、当前Gaussian EI和权重调度；16点全部训练。区别于四臂中的Sobol16/v3选8的BO，不能合并成同一条方法。
- 三者均做每种子50次新增唯一候选的实际评价，避免把50代与50次单点BO混为等成本。相比从零建立新池，复用已经深审计的数值池节省求解，且与预先设计的外部面板一致。已有LLMBO/WarmStart-only轨迹用作冻结参照，不改其参数或重新挑种子。

## 数据、初始化和签名

复用f1101的5个种子872104、195447、221402、513225、162634及0.5C/1C各60秒观测。倍率、数据、物理模型、边界条件、参数范围及目标定义逐字节沿用；不使用3C或实测数据。各种子三基线使用相同有序16点。

旧8点计划不可直接按16点加载。先通过旧完整池深审计，严格核对data/model_evaluation/evaluation_protocol/comparison_protocol/source/fit_rates，再用明确的`derived_full16_plan_v1`生成目标配置的16点签名和来源桥接证明。物理参数、曲线、目标和旧成本保持，只有已声明的初始化策略/签名变更。不会放宽旧缓存校验。派生计划保留原池路径、原签名、原文件哈希、16点记录摘要和历史成本，重新校验全部曲线。

ParEGO使用现有原生配置；外部算法的同一v2配置仅承担评价器输入契约，实际算法身份、配置、库版本和状态单独在baseline-contract.json与baseline-rounds中绑定，不能将其声称为parego。

## 进程、依赖与失败

NSGA-II/SMPSO在独立Python环境中运行官方算法，通过JSON行协议请求候选评价；不能导入PyBaMM或自行联网。DFN worker使用原锁定解释器，单线程，统一扣费和归档。独立安装不升级原DFN环境。

官方算法初始化由指定16点生成器提供，原初值在DFN侧核验后返回。重复候选只返回验证过的完整缓存，不增加真实求解或训练样本；不同输入同目标保留。50次新评价上限精确在评价边界停止，末代未完成状态明确记录；不为补齐一代超支。有限候选提议守卫和每次/每任务超时防死循环，不设额外总费用额度。

求解失败保留部分U/T和实际成本；无法形成完整目标对时不给外部算法伪造零或惩罚目标，该臂右删失并继续其他预定臂。所有失败、筛选、重复、缓存及新增成本分别记录。

## 验收与分析

先RED/GREEN和二维已知软件问题，验证官方算法来源、种子复现、16点共享、50新点精确停止、partial不补零、末代截断、无API/DFN调用及冷spawn。再跑15组各10轮软件演练，通过后冻结源码并直接运行15组各50轮真实DFN合成对照。预计新增1500次DFN，API=0；历史初始化成本单列不冒充免费。

每轮使用固定(F_U/0.1,F_T/1)、reference=(10,10)独立复算HV；完整真实记录进入外部Pareto。用同一个对称Pareto代表点给U/T误差，检查0、1、3、5、10、20、50；主早期终点仍为梯形平均AUC_HV(0..10)。报告所有逐种子配对差值、均值/中位数/胜负数、实际成本和墙钟。n=5不宣称显著性，旧已见结果不是新确认集。不能因负结果改变超参数或重选种子。
