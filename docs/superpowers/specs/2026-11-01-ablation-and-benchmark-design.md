## 2. 固定科研问题与数据

使用同一组六参数 `eps_s_n, eps_s_p, D_s_n_ref, D_s_p_ref, C_th, G_th`，同一次 DFN+lumped 求解产生电压和体平均电芯温度。沿用 PyBaMM 25.10.2、Chen2020 固定物性及已存档的温度反馈映射。

快速阶段复用已有 0.5C/1C、60 s 的真实 DFN 合成观测，倍率、时间网格、初态、热边界、参数范围、变换及全部观测逐字节冻结。`F_U` 和 `F_T` 为配置内倍率的平均 RMSE；这是短窗口算法筛查，不是实测辨识或参数可辨识性证据。当前实测输入仍有待确认项，旧 3C 不进入试验。

LLM 请求不得包含观测 provenance 中的 `known_parameters`、生成真值或后续轮次结果。生成真值保存在审计档案，不用于提出候选、挑选种子、GP 先验或决定停止。

## 3. 四臂消融：2×2 配对设计

| ID | 方法 | WarmStart | Region | 初始化来源 | 数值骨干 |
|---|---|---:|---:|---|---|
| A00 | BO | 0 | 0 | 数值池 N | 当前 ParEGO+ARD Matérn+Gaussian EI |
| A10 | BO+WarmStart | 1 | 0 | LLM 池 W | 同 A00 |
| A01 | BO+Region | 0 | 1 | 与 A00 相同有序八点 N | 同 A00，开启现有 Region |
| A11 | LLMBO | 1 | 1 | 与 A10 相同有序八点 W | 同 A00，开启现有 Region |

为使初始化的真实成本相等，每种子 N 和 W 各评价 16 个唯一候选，再用同一个 v3 规则选 8 个 GP 初始化点。N 来自现有 `Sobol6` 的种子索引块（非 scrambled Sobol）：数值池从 `seed*1024` 开始，LLM补点从 `seed*1024+256` 开始，B0后续提议从 `seed*1024+512` 开始。各用途流不重叠。W 首先使用 LLM 提议。v3 是确定性的筛选器，本身不依赖 LLM，因此也用于数值池的匹配成本控制。此处 BO 应准确标为“ParEGO，Sobol16/v3→8”，不能声称它是未经初始化筛选的默认 ParEGO。

这一设计隔离的是 LLM 候选生成、Region 和二者交互。它不再估计 v3 相对其他筛选器的贡献。

N 池只实评一次，供 A00/A01 导入；W 池只实评一次，供 A10/A11 导入。共享文件用独立初始化兼容签名与 SHA 绑定；不能把 LLM 开关混入可共享的物理评价身份。不同臂后续观测互不传递。权重序列、候选池随机流、GP 拟合次数/停止规则及数值精度在消融中保持一致；提议噪声采用按用途分离的 RNG，不能因 API 调用消耗 BO 随机流。

同种子配对效应（HV 等越大越好指标）：

\[
\Delta_W=\tfrac12[(Y_{10}-Y_{00})+(Y_{11}-Y_{01})],\quad
\Delta_R=\tfrac12[(Y_{01}-Y_{00})+(Y_{11}-Y_{10})],
\]
\[
\Delta_{WR}=Y_{11}-Y_{10}-Y_{01}+Y_{00}.
\]

同时直接报告 A10−A00、A01−A00、A11−A10、A11−A01，不能只给平均主效应掩盖条件差异。RMSE 差值以负值为改善。

## 4. 初始化补足与失败：消除“15/16 导致全试验停止”

预注册候选完成策略 `llm_then_sobol_fill_v1`，v3 排序公式不变：

1. W 池最多 3 次应用层提议请求、累计最多 48 个提议；每次只请求当前缺少数量。无自动传输重试。
2. 代码先严格验格式、签名、范围、物理可行性和参数键，重复点不新增求解。错误回复和重复都留档并计入相应请求/筛选成本。
3. 用完请求机会后，若完整唯一候选少于 16，从专用 Sobol 流补足尚未使用的候选。最多检查 128 个补点提议；总真实候选评价尝试不超过 16，每候选最多按配置倍率求解一次。补点不补造目标、不增加总评价额度。
4. 保存每点 `LLM`/`Sobol_fill` 来源、LLM 占比、拒绝与重复原因。两条 W 臂共享完全相同的混合池。此策略是新的实验协议，与旧纯 LLM 16 点协议分开归档。
5. 若存在失败求解，保留部分电压/温度诊断，不补零；该种子若无法形成 16 个完整点，标为初始化失败。不能把 15 点伪称 16 点，也不能按结果另换种子。其余预定种子仍继续，完成率必须报告。
6. Region 每轮最多一次请求；无效、超时或低置信区域按现有规则回退 plain EI。回退轮保留在 Full 的主分析中，不事后删掉。

这份初始化完成策略尚需接入监督器；旧三臂监督器仍固定 16 点且遇不足时停止，不能直接冒充新四臂执行器。

## 5. 外部比较：完整方法的等真实成本比较

| ID | 方法 | 类型 | 比较作用 | 当前可用状态 |
|---|---|---|---|---|
| B0 | Sobol | 非自适应 | 检查代理模型/LLM 是否有超出空间覆盖的收益 | 有 Sobol 设施，需评价包装 |
| B1 | ParEGO-16 | 经典 MOBO | 随机标量化基准 | 有数值骨干，需初始化模式包装 |
| B2 | NSGA-II，population=16，offspring=1 | 经典进化 | 排序与拥挤距离控制；明确为 steady-state 设置 | pymoo 未安装，需适配 |
| B3 | MOEA/D，16 个参考方向 | 经典分解 | 区分分解思想与 LLM 的收益 | pymoo 未安装，需适配 |
| B4 | qLogNEHVI，q=1 | 现代 MOBO | 直接优化联合 HV 改进 | BoTorch/PyTorch 未安装，需适配 |
| B5 | 多目标 JES，q=1 | 现代信息论 MOBO | 联合学习 Pareto 参数/目标信息 | BoTorch/PyTorch 未安装，需适配 |
| A11 | LLMBO(v3+Region) | 本方法 | 完整流程比较 | 复用四臂消融中的同一条轨迹 |

B0–B5 共享 N 的 16 个真实初始化评价，全部作为其历史；B1/B4/B5 用全部 16 点训练，进化方法用 population=16。A11 仍保持 v3 16选8 的已定训练策略，不能为迎合基线改成另一种 LLMBO。各方法都花了 16 次初始化评价，所有已获得的完整候选进入外部评价档案。此面板比较完整流程，不等同于只换采集函数。

因此 B1 与 A00 是两条有清楚标注的初始化变体，不能合并统计或重复当作独立复现。这样避免强制所有基线只用八点而人为削弱它们。

详细适配：

- NSGA-II：在归一化六维参数中运行，SBX(prob=0.9, eta=15)，polynomial mutation(prob_var=1/6, eta=20)，`n_offsprings=1`，去重；逐个评价，population=16。小预算 steady-state 结果不能概括经典大种群算法的充分预算表现。
- MOEA/D：均匀二维参考方向 `[(i/15,1-i/15),i=0..15]`，neighbors=5、邻域交配概率=0.9，SBX/PM 同上，Tchebycheff 分解；串行子问题更新，精确以新评价数停止。只有候选可行后才调用评价器。不能把不可行物理点当成伪造的惩罚目标送入共同 Pareto/HV。
- qLogNEHVI：独立输出 ARD Matérn GP，float64/CPU、q=1；在 `Z=(-F_U/0.1,-F_T/1)` 最大化，reference=(-10,-10)。两个目标的后验标准化与 acquisition reference 必须匹配。Log 指采集函数的数值实现，不能对 RMSE 再做旧的 log/max(value,1) 变换。
- MO-JES：使用 Tu 等的多目标方法及官方实现的 lower-bound approximation，记录精确类名和 estimation_type；默认 LB、32 个 Pareto 样本、64 个积分样本。禁止误接同年另一篇单目标 JES，或把 scalar MES 当作 MO-JES。若官方 API/采样不兼容，标为未实现，不能静默改成 EI。
- 两种现代 GP 基线先用已公开合成函数确定 MC/优化精度，候选设置：128 个 QMC acquisition 样本、256 raw starts、8 restarts、maxiter=100；确定型噪声下固定 noise floor（标准化空间 1e-6）。正式电池数据与确认种子不参与调参。记录模型拟合和选点墙钟，不能把更高数值预算带来的增益归给 LLM。
- 外部依赖进入独立基线环境；通过本机兼容检查后生成实际 lock+wheel/hash。当前官方文档版本是参考，不能当成本机已锁定版本，也不改现有 DFN 解释器。

## 6. 主指标和前十轮分析

固定指标空间 `(F_U/0.1,F_T/1)`，minimization reference=(10,10)；最大可能 HV=100。尺度、reference 和观测不按种子或算法重新拟合。

每轮 k=0..10 输出：

- **主要终点**：`AUC_HV_0_10 = (1/10) sum_{k=1}^{10}(HV(k-1)+HV(k))/2`。配套报告 HV(10) 与 HV(10)−HV(0)。
- 关键误差终点：同一个对称代表点的 `F_U`(mV)、`F_T`(K) 与 `Q=max(0.5 F_U/0.1,0.5 F_T)+0.05(0.5 F_U/0.1+0.5 F_T)`。固定理想点为零；从当前已观察 Pareto 集选最小 Q，同分按归一化参数、评价 ID。不能分别摘取两个不同参数点的最小 RMSE 拼成一个解。
- 固定检查点 0、1、3、5、10；延伸检查点 20、50。记录所有逐轮值，不事后挑有利轮数。双目标各分量无需单调，Q/HV 反映折中。
- 指标档案包含初始化池全部 16 个完整实评点，而不只八个 GP 点。GP 历史和可取得解的评价档案分开记录；每个被筛掉的真实点仍可作为最终 Pareto 候选。旧试验仅用选中八点计指标的曲线不能混入本协议。
- 另给“从第一次真实评价起”的成本横轴：初始化计 16 次候选评价，k 轮后合计 16+k；两倍率上限 2(16+k) 次 solve。逻辑成本和共享池带来的物理节省分列，任何跨臂共享只能发生于预注册初始化池。
- 失败/筛选/缓存/API 全部独立计账。缓存不新增 GP 样本；同目标不同参数仍是不同样本。若没有已确认的完整目标对，指标为缺失而非零。失败后曲线右删失，不能补成成功终局。

仅五个种子是五个独立配对单位，50 个逐轮观测不是50次独立实验。快速筛查报告每种子差值、均值、中位数、正负数和完成率，不宣称显著性；后续用预先生成的另五种子确认。三个 Full 对消融的条件对比属于预定比较；扩展多方法显著性如需使用，至少合并十个种子并预注册配对检验与 Holm 校正。不能在看到单个好种子后提前宣布成功。

## 7. 种子、运行次序、成本与停止

配置生成器确定性地产生 10 个新种子，排除已用种子；前5为快速筛查，后5为确认。四臂和外部方法分别采用循环平衡次序，每轮权重表及独立 RNG 种子均写入任务矩阵。种子生成后不因目标值或 API 回复而变更。

每种子的物理共享初始化成本：N16+W16=32候选，乘2倍率=64 solve。四臂各10轮再需80 solve；最多3次WarmStart+20次Region=23 API。因此五种子四臂快速阶段最多 **720 DFN、115 API**。请求上限包括失败请求，无额外预检免费次数。

六个外部基线每种子各10轮，在复用同一 N 池和 A11 轨迹的条件下，额外 **600 DFN、0 API**。合计快速设计最多 **1320 DFN、115 API**，不重新生成已有合成观测。API token/超时沿用模板：WarmStart与Region均最多8192输出tokens/请求、120秒；须与最终冻结配置和端点能力验证一致。预估值不表示新预算已获批。

统一延伸到50轮时，四臂合计2320 DFN/515 API，外部基线额外3000 DFN，联合上限5320 DFN/515 API。五种子快速主流程建议独立8小时上限；延伸需按真实耗时另定。累计ledger、绝对deadline、已完成阶段/请求ID必须跨重启核验；不能以“允许一直启动”为无限预算。

失败策略：先封存失败原因和成本；可恢复基础设施问题在同一总次数和deadline内继续，求解不重传、不把同一输入重复加入GP；候选池不足按预注册补点策略处理。单个种子失败不使剩余全部种子静默丢失。脚本错误不能不断花API试错。

## 8. 实施边界与验收

当前三臂 worker 的 ARMS 只有 bo/warmstart_only/full_llmbo_mo，不能直接表示 Region-only；现有数值初始化固定八点，其旧规则校验只列出v1/v2，也不能直接执行新数值池v3筛选。必须建立十六点数值池、按v3签名导入，并以数值初始化+full Region mode 明确路由；用测试证明没有额外 WarmStart请求。直接启动器对 `_live_preflight` 的临时替换只用于旧紧急运行，不进入新主线。

启动验收聚焦有意义的风险：四臂实际调用计数、共享初始化一致性、Region-only首轮训练数据来源、v3审计、缺点补足上限、Windows冷启动及短归档路径、恢复后累计预算/绝对截止、已归档曲线重算。现代基线还须通过二维已知问题、最小化/最大化符号、相同输入重复、V→mV尺度同步不变、Pareto/HV审计。配置准备通过不等于算法适配或真实效果验证。
