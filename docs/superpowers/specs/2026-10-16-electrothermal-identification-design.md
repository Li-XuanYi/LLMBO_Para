## 1. 目标、范围和研究边界

保留完整 voltage-only 路线；新增 electrothermal_identification 路线。同一候选参数在每个工况的一次 DFN＋集总热求解中产生电压与电芯温度。四倍率为 0.5C、1C、2C、3C；每倍率分别计算电压和温度 RMSE，再分别等权平均。目标顺序固定为 `[F_U, F_T]`，原始单位为 V、K，均最小化。温度目标不奖励低温或低温升。

首版仅支持共同冷却边界的一组四倍率工况及一个六维方案。不同冷却组、空间热传导、额外 SOC/热导率变量、任意维数插件平台均不在本轮实现范围。未知实验条件阻塞正式实测辨识，但不阻塞接口、mock 和合成验证。

## 4. 参数与配置契约

旧配置继续 `schema_version=1`，走旧验证和 voltage-only 行为。新配置使用 `schema_version=2`、`problem_type=electrothermal_identification`、`parameter_profile=electrothermal_4e2t`。未知版本、混用 profile 或物理单位错误均拒绝。

| 优化变量 | 角色 | 单位 | 搜索变换 |
|---|---|---|---|
| eps_s_n | 负极活性材料体积分数 | 1 | linear |
| eps_s_p | 正极活性材料体积分数 | 1 | linear |
| D_s_n_ref | 参考温度下负极固相扩散率 | m²/s | log10 |
| D_s_p_ref | 参考温度下正极固相扩散率 | m²/s | log10 |
| C_th | 整电芯有效热容 | J/K | 显式配置 linear 或 log10，首版合成配置用 log10 |
| G_th | 有效散热导纳 | W/K | 显式配置 linear 或 log10，首版合成配置用 log10 |

## 5. 模型映射

已直接检查安装源码，25.10.2 接受：

```json
{"thermal": "lumped", "use lumped thermal capacity": "true", "surface temperature": "ambient"}
```

实际 PyBaMM 键与映射：

- `Cell volume [m3] = V_cell`，`Cell cooling surface area [m2] = A_cooling`，均为配置中的固定正数。
- `Cell heat capacity [J.K-1.m-3] = C_th / V_cell`。
- `Total heat transfer coefficient [W.m-2.K-1] = G_th / A_cooling`。

参数库可能没有集中热容键，映射层可仅为该已核查键显式新增；其余键继续校验存在性，不整体关闭 PyBaMM 参数校验。归档模型处理后实际热容、热体积和冷却面积，核实模型使用的体积与映射体积一致。

扩散函数为 `D_ref * exp[(E_D/R)*(1/T_ref - 1/T)]`，保留 PyBaMM 所需 `(stoichiometry, temperature)` 调用签名，使用符号兼容函数。测试在 T_ref 恢复 D_ref、温度变化方向及非零反馈。不能把函数替换为 float。

Chen2020 默认固相扩散率为常数，OCP 熵变为零。首版不虚构熵变；如使用非零扩散活化能，研究配置必须提供来源。合成 fixture 的非零活化能明确标成测试设定，不能引用反应交换电流的活化能充当扩散数据。

一次 `Simulation.solve` 返回 `Terminal voltage [V]`、`Volume-averaged cell temperature [K]` 和配置实际全部热源/冷却诊断。默认 `Surface temperature [K]` 来自 Ambient 子模型，等于环境温度，禁止用作电芯预测目标。表面探头近似体平均状态必须有明确研究假设；首版不实现表面第二节点。

保留 parameterization / explicit_soc 旧初态路径与 NumPy eSOH 兼容修复。新配置显式提供初始电芯温度及独立环境温度，不自动相等。

## 6. 数据与评价接口

新类型分别表达：输入 I(t)、T_amb(t)、初态、冷却组；观测 U_obs(t_U)、T_cell_obs(t_T)。各网格严格递增、有限、至少两个有效样本，温度允许独立采样时刻。输入必须覆盖所需求解窗口，两个目标必须分别有完整覆盖，禁止外推或按候选改变评价掩码。

读入边界执行唯一一次 ℃→K；内部字段带 `_k`，归档原单位与转换记录，恢复档案不二次转换。RMSE 温差的 K 与 ℃数值相同。测得温度后续值不参与模型输入；固定参数/工况/初始温度，仅篡改后续目标温度，预测不变而误差变化。

每倍率结果保存原始和对齐 U/T 曲线、各自 RMSE/有效性、事件、所需终点/实际终点、错误类别与尝试成本。任一倍率任一必需目标无效，完整目标为 null，不进入标量 GP/Pareto；保留其它有效输出供诊断，不填零、惩罚值或重叠区间误差。

研究预检汇总列出缺失实际电流、时间来源、T 单位/测点、初态、环境温度、共享冷却组、几何和物性来源。首版遇到不同或未知冷却组阻塞研究运行，不自动强迫一个 G_th 或增加四个 G_th。现有 I 空列和 T 待确认状态完整保留。数据模板拒绝运行是预期验收结果。

## 7. 数值多目标骨干

保存真实 `Y_raw[n,2]`。首版目标变换 identity；尺度 `s=[s_U,s_T]>0` 为运行前显式冻结的物理尺度，比较路线使用同一尺度。研究尺度由实验精度/容许误差确定；合成尺度只服务测试。首版不使用动态目标范围，因而没有隐含范围下限；若后续加入，需独立版本与明确下限。

理想点由当前完整历史的分量最小值计算；仅使用已获得数据。每轮冻结 `(w,s,zstar,rho_aug)`，定义 `a_j=abs(F_j-zstar_j)/s_j`、`g=max(w*a)+rho_aug*sum(w*a)`。建议首版 `rho_aug=0.05`，依据参考源码并显式配置。

二维权重采用显式 simplex 网格与带种子的无放回循环；检查两个分量非负、和为 1。原实现也支持有放回随机模式，本轮只迁移确定可重放的无放回机制。权重数与网格端点规则写入配置；不继承三维 Riesz 生成的硬编码。

每轮完整重建：当前历史的 g → g 的线性均值/标准差 → 全部 GP 标签 → 新 GP 拟合 → 当前 incumbent 与对应局部中心 → 同空间 EI。无新有效观测但换权重也必须重建。常数标签使用标准差 1；不调用旧 LogRMSETransform 或 scalar_log_ei。GP 复用现有六维底层，group 为空、lengthscale_prior 为 None，保存实际拟合预算/停止原因/超参数。

高斯 EI 在同一线性标准化空间计算。sigma→0 时为 `max(best-mu,0)`，避免照搬原代码零方差全部返回零的边界行为。物理 V→mV 且同步换目标尺度，训练与选点应一致。

上下文指纹覆盖完整历史记录 ID/标签、profile、权重、尺度、理想点、变换版本、GP 状态和候选池。所有真实失败消耗尝试预算。全局/局部配额、过滤、数值回退三条对照路线一致；首版不默认叠加可行性概率模型。

## 8. Pareto 与指标空间

仅完整真实目标对参与非支配筛选；相同目标可保留多个参数解，HV 去重。最终输出 Pareto 参数集及双误差、曲线与来源。代表解按独立配置规则挑选，不能替代完整集合。

HV 使用运行前固定的误差尺度与固定参考点；不减去每轮动态理想点。二维矩形并集用可独立手算的精确算法，无新增 pymoo 依赖。无正式参考点时输出 Pareto，HV=null 并说明未配置；参考点外或边界点贡献零，不改变参考点追随数据。跨运行比较核对指标空间指纹，不一致时拒绝直接比较。

## 9. 两个 LLM 作用

三条路线：ParEGO（WarmStart off/Region off）、WarmStart-only（on/off）、完整 LLMBO-MO（on/on）。新 profile 禁用旧参数组混合核与 LLM 长度尺度先验组合；旧路线不变。
