# 电热耦合参数辨识：论文证据链与可执行实验协议（2026-11-06）

## 1. 研究问题与证据边界

研究主线：在固定且可追溯的 DFN–lumped thermal 模型、物理参数域和测量数据下，检验 LLM 引导的 WarmStart 与 Region-Lift 是否改善电压–温度双目标参数辨识的计算效率、稳定性与物理预测能力。

参考论文：
- Kuai et al., Large language model-enhanced Bayesian optimization for parameter identification of lithium-ion batteries（2025；实验见第 6–11 页）：四倍率拟合、优化器比较、Prompt 消融、Morris、预算与老化电芯。
- Zhang et al., Generative Parameter Identification of Electrochemical Model of Lithium-Ion Batteries via Response-Guided Distribution Learning（2026 TTE 投稿稿件；实验见 PDF 第 8–12 页）：15 次重复、270 次评价、AUC、胜率、无效评价率、near-best 转化和机制消融。

当前既有证据：
- `runs/f1101`：A00=BO、A10=BO+WarmStart、A01=BO+Region、A11=两者组合；5 seeds × 50 BO rounds，0.5C/1C、每倍率 60s、合成 DFN 数据；原始预算 2320 DFN + 505 API。
- `runs/evidence-audit-20261106`：由完整 `f1101` 归档读取得到的参数恢复及配对效应（独立只读复算）。
- `runs/n1104-review`、`runs/cr1103-review`：保留种子在看到结果后筛选，属于探索性描述；不能作为独立确认性结论。
- `runs/hv01-20261105` 与 `runs/hv-reference-sensitivity`：观察结果后调整 HV 参考点；需区别历史原定口径和新实验预先固定的口径。
- `docs/audits/electrothermal-identification-scope-2026-10-16.md`：实测表 I 列空白，T 单位/测点不明确，3C 温度工况异常待确认。实测联合拟合仍需数据来源核实。

所有新增研究独立存放 `runs/et-paper-20261106/` 的子目录，既有数据和代码历史保持原样。未经记录的参数范围、环境温度、传感器精度、热模型边界不得凭经验填充。

## 2. 全部实验共同约束（冻结协议）

1. 主变量固定为 [eps_s_n, eps_s_p, D_s_n_ref, D_s_p_ref, C_th, G_th]；固相扩散率在 log10 坐标建模。其余模型参数和输入边界明示，并保存单位和来源。
2. 比较以“累计真实 DFN 求解次数”为主预算，完整计入初始化候选、可行性筛选、失败/重试和各倍率求解；并行报告墙钟时间、API 调用/费用。软件计算、缓存命中和重复结果单独列账。
3. 每次主比较采用相同物理任务、共同的随机种子、相同候选预算、相同可行性/失败判定。额外报告“完整系统”（包含各自 WarmStart）和“共享初始化”（隔离优化器）的两种比较。
4. 双目标为各倍率汇总后的电压 RMSE F_U（V）与温度 RMSE F_T（K）。保留每个倍率原始残差；优化内使用事前固定的 [0.1 V, 1 K] 目标尺度，统计时也报告未归一化误差。
5. HV 参考点在新试验的冻结配置中事先基于工程允许误差/独立预实验确定。历史 (10,10) 口径仅用于历史复算；(1,1)/(0.8,0.9) 的既有历史探索作为敏感性结果保留。禁止看到新种子结果后改变主参考点。
6. 随机种子、新工况、噪声等级、评价预算与停止条件写入协议及哈希清单。主结果使用完整的独立种子集合；优化轮次不能当作独立统计重复。
7. 构造 synthetic truth 时，记录 DFN 方程、模型网格、真值参数、SOC、温度、倍率、电流、测量时刻。实测参数无真值时仅做预测误差和稳定性验证。
8. 运行日志包括代码快照哈希、依赖版本、输入文件 SHA256、候选参数、每倍率 Solver 结果、目标值、失败原因、优化器选择、请求响应摘要、最终 Pareto 集。
9. 主表必须展示 95% 配对置信区间及各随机种子结果；样本量较小时同时给出符号一致性、效应量、个体散点，不把未显著的差异描述为确定优势。
10. 数据处理 / 复算脚本不得自动触发 DFN 与外部 LLM API。新增仿真与 API 批量运行必须在独立预算清单、完整性检查及费用估算后执行。

## 3. E1：电热联合辨识有效性（P0）

假设：相同六参数域和样本预算下，联用 U/T 观测可改善两类响应的权衡，并对部分参数增加约束。

实验组：Voltage-only (F_U)、Thermal-only (F_T)、Joint (F_U,F_T)。为隔离观测目标的效应，统一采用相同初始化与数值 BO 主体；Joint 用固定的多目标标量化/权重日程，单目标使用对应 EI，三个组使用同一物理模型、相同参数域、相同每倍率观测网格和累计 DFN 预算。每组最终统一在 (F_U,F_T) 平面评价。

计划：15 独立种子；每种子 16 个共享初始化候选 + 每臂 50 个新候选；0.5C/1C 两倍率。最小理论预算：15 × (16 + 3×50) × 2 = 4980 倍率求解；预处理失败、重试成本单独计入，不允许隐性豁免。

输出：双目标前沿/固定 HV、六参数误差与相关性、逐倍率 U/T 曲线。单目标结果按统一双目标评价口径展示。

附加物理消融：在完全相同参数与输入下关闭温度相关物性的反馈，验证双向耦合对电压动态及辨识结果的影响；明确模型适用边界。

## 4. E2：参数灵敏度、可辨识性、恢复误差（P0）

已有只读结果：`scripts/analyze_et_f1101_evidence.py` 复算五种子 × 四臂的最终对称 Pareto 代表点相对生成真值的六参数误差。只有一组固定合成数据，算法种子属于随机优化重复。

新增验证：
- 对归一化的参数 z 进行 Morris 全局敏感性分析，分别量化 U/T 响应和两种误差目标；
- 构造以噪声标准差白化的 U/T 观测 Jacobian（有限差分），分析 SVD 奇异值、Fisher 信息矩阵和高相关参数对；
- 对热参数 C_th、G_th 以及弱可辨识扩散率开展 profile likelihood/参数补偿图；
- 比较 60、300、600 秒等可完成的放电/冷却观测窗口，时间和数据点数在事件截止下严格验证。

输出：六参数 Morris 双目标敏感性热图，奇异值谱、恢复误差箱线/散点、热时间常数与观测长度分析。Morris/SVD 的计算成本另行预估并在实验 manifest 中冻结。

## 5. E3：跨工况和长时泛化（P0）

将现有训练条件 0.5C/1C、60s 固定为 in-distribution；以 2C/3C 更长时间、相同倍率更长窗口、冷却段或脉冲工况构造严格 held-out 的独立验证集。真实/合成观测的电流、SOC、温度、热边界必须完整一致且记录。

复用已有 5 seeds × 4 arms。每组每种子通过事前冻结规则选取 Pareto 两个端点 + 一个折中点；对于两种未见倍率的单次检验，最小附加 5×4×3×2=120 次 DFN 求解。所有方法使用同一选点规则，并保留完整误差时序、峰值温升、最终温度、截止误差。观测生成器需独立于拟合用的数据文件。

附加模型失配：改变观测生成网格、设定测量噪声/热边界扰动，明确属于合成鲁棒性检验；不得与实测结果合并。

## 6. E4：评价预算利用率与收敛机制（P0）

可从存量数据复算：每次候选的有效性、初始与后续累计求解成本、HV 轨迹、首次达到共同质量门槛的累计预算。

推荐指标：最终 HV、HV-AUC、首次达到目标的 solver-call 次数、有效评价率、competitive-feasible 评价率、首次取得竞争性候选的种子比例、时间与 API 花费。仿照 GPIM 将候选分为 invalid、feasible noncompetitive、feasible competitive。门槛在新实验前事先冻结；如对旧记录探索性计算，需标注阈值事后选定及不做确认性推论。

注意在同一预算时刻使用截至该时刻已知的 Pareto 前沿，禁止用未来结果指导过去的真实优化。重复候选与缓存单列，不重复记入“新有效信息”。

输出：budget-conversion 分层条形图、hit-rate 曲线、HV vs 累计 DFN 次数、HV-AUC 统计表。

## 7. E5：Region / Prompt 机制与反事实选点（P0）

比较 Plain EI、真实 LLM Region、随机合法 Region、打乱上下文的 Region、无领域信息 Prompt、无历史摘要 Prompt；每个控制实验必须维持相同候选池、GP 后验上下文、初始数据和调用预算。

在存量 A01/A11 决策中提取“selection_changed”轮次及候选差异；进一步在冻结的同一 GP 上下文中，对 Plain EI 与 Region 建议的两个候选进行同条件 DFN 评价，计算单步 ΔHV、真实候选收益和调用成本。候选同时已评价则可复用缓存；对未评价的反事实候选记真实新增 solver-call 成本。禁止从已经分叉的两条轨迹直接归因单次选点的因果作用。

输出：建议采纳率、改变选点率、Region 成功率、ΔHV 差异、Region 的有效/无效边界及逐轮案例。主分析与探索性的历史反事实分开报告。

## 8. E6：独立多种子统计和预算敏感性（P1）

对完整四臂 A00/A10/A01/A11 预设 15 个独立随机种子，评估轮数 25、50、75 对终值/曲线的影响。25/50 可以从 75 轮轨迹提取，但所有组需要相同初始化、固定主指标和完整成本。

若固定 50 轮、16 个候选池、0.5C/1C 两倍率，按当前五种子的相同执行结构估算，15 seeds × 4 arms 的总预算约为 6960 DFN 求解 + 1515 API 请求（随缓存、失败与 LLM 重试改变）。该数字是估算，不能替代运行前真实预算核查。

优先统计 15 种子的配对 HV/HV-AUC、正向种子比例、置信区间及失败调用账本。确认性种子预先固定、全部披露；历史事后筛选记录保留作探索性补充。

## 9. E7：实测电热联合辨识（P0，依赖观测确认）

实测资料必须明确每倍率真实电流/额定容量换算依据、温度 T 列单位/探头位置、环境温度、初始 SOC、冷却和 3C 数据处理记录。核对 2C 末段温度序列；对 3C 异常温度列保持原始不可改写。

获得确认后的数据可执行四倍率完整电压/温度轨迹拟合、逐点残差、不同倍率留一验证、其他电芯或老化状态测试。保持真实测量数据与 synthetic truth 分离；同一工况模型标定/验证的划分事先冻结。

输出：实际 U/T 拟合曲线、各倍率误差表、峰温和截止误差、拟合/测试差异、完整参数及条件记录。
